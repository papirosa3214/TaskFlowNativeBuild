# Макет: стартовый экран чата с ролью (пустой чат)

Одноразовый макет, в приложение пока не внесён. Показывает, как может выглядеть
экран личного чата с ролью, когда сообщений ещё нет: приветствие роли и быстрые
команды.

## Как открыть

```bash
open mockups/role-chat-start/index.html
```

Слева — список ролей, переключение подачи и темы. Тап по роли меняет экран,
тап по быстрой команде подставляет текст в поле ввода.

## Что внутри

- 11 ролей — как в живом реестре сервера (`New-Todoist/server`, таблица `roles`,
  все 11 включены): Исследователь, Аналитик, Критик-проверяющий, Архитектор,
  Разработчик, Лайф-тестировщик, Дизайнер, Помощник владельца, Оркестратор,
  Инженер .110, Claude Code.
- Формулировки «кто есть кто» и звенья команды — из `server/src/lib/teamStructure.ts`
  и `server/src/roleRouting.ts` (описания ролей и их обязанности), портреты —
  из `Resources/Assets.xcassets/RoleAvatar*.imageset`.
- Цвета, кегли, отступы и радиусы — по `DESIGN.md` (тёмная тема по умолчанию,
  светлая — переключателем).

## Две подачи

| | Вариант А — карточка | Вариант Б — пилюли |
|---|---|---|
| Приветствие | крупно: портрет, звено, чем роль занимается, что предлагает | компактно: портрет, одна строка о роли, одна фраза от роли |
| Команды | 4 карточки в сетке 2×2: заголовок + подсказка | пилюли в один поток, как плашки быстрых ответов под сообщениями роли |

## Ссылка на конкретный вид

`index.html#variant=pills&role=builder&theme=light&solo=1`

- `variant` — `card` | `pills`
- `role` — `researcher`, `analyst`, `critic_verifier`, `architect`, `builder`,
  `qa`, `designer`, `secretary`, `code_orchestrator`, `infra_engineer`, `claude_code`
- `theme` — `dark` | `light`
- `solo=1` — без панели ролей, только экран

## Чего в макете нет

Это только вид. Не описаны отправка, разные состояния (груз, ошибка), длинные
тексты, тёмная/светлая синхронизация с системной темой, поведение под
Dynamic Type.
