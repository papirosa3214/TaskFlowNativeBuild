# Как режется работа между исполнителями

Порядок продиктован зависимостями: без каркаса экраны писать не на чем, без
спецификаций каркас пришлось бы выдумывать.

## Волна 0 — разведка (идёт)

Снимается с веб-версии всё, по чему потом пишут нативные экраны. Результат — файлы
в `spec/`: `API.md`, `DESIGN-TOKENS.md`, `SCREENS-1.md`, `SCREENS-2.md`,
`NATIVE-PARTS.md` и папка `screenshots/` с эталонными кадрами всех экранов в размере
телефона владельца.

## Волна 1 — каркас (один исполнитель, остальные ждут)

Единственный кусок, который нельзя параллелить: всё остальное на него ложится.

- `Core/`: модели данных, `APIClient` (async/await), хранение сессии и токена,
  сторы задач/проектов/меток, обработка ошибок, реалтайм-канал.
- `DesignSystem/`: цвета, шрифты, отступы, радиусы из `spec/DESIGN-TOKENS.md`;
  базовые кирпичи (строка задачи, чекбокс, бейдж, пилюля приоритета, шапка экрана,
  пустое состояние, шторка).
- `App/`: корневая навигация, нижняя панель с центральной кнопкой, вход/регистрация.

Приёмка: приложение запускается, логинится к серверу на :3001, показывает список
задач хотя бы плоским списком, нижняя панель переключает пустые экраны.

## Волна 2 — экраны веером (параллельно, по папке на исполнителя)

| Кусок        | Что входит                                                            | Опирается на |
| ------------ | --------------------------------------------------------------------- | ------------ |
| Ядро дня     | Сегодня, шкала часов, Предстоящее с календарём, Обзор, Входящие       | SCREENS-1    |
| Задача       | карточка задачи, форма создания и правки, шаги, журнал, перенос срока | SCREENS-1    |
| Заметки      | список заметок и редактор с форматированием                           | SCREENS-2    |
| Чат и агенты | чат, работа агента, список агентов                                    | SCREENS-2    |
| Справочники  | проекты, метки, поиск, активность, уведомления                        | SCREENS-2    |
| Настройки    | настройки, интеграции, шаблоны, голосовые модели                      | SCREENS-2    |

## Волна 3 — нативные особенности

- Своя экранная клавиатура через `inputView` — то, ради чего натив и затевался.
- Перенос готового Swift: виджеты, Live Activity, календарь (EventKit), хаптика,
  App Intents. Из них выпиливается зависимость от Capacitor-моста.

## Волна 4 — сведение

Сборка на устройство, сверка каждого экрана со скриншотом из `spec/screenshots/`,
правки по расхождениям, потом отдача владельцу на живую оценку.
