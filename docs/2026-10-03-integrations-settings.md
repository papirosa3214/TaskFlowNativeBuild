# Интеграции в стиле настроек — 03.10.2026

## Сделано

Группы оформлены теми же TFCard / TFListRow, что настройки: plain-значки, action-типографика, compact-строки и разделители без промежутков между сервисами. Убраны цветные подложки значков, цветные статусы и отдельные рамки аккордеонов. Между тематическими группами сохранён интервал экрана настроек.

Все сервисы сначала свёрнуты. Composio и Linear раскрываются на месте, одинаковым поворотом шеврона и анимацией. Их содержимое используется повторно и для отдельных экранов; вложенного ScrollView при раскрытии нет. Подключение Linear раскрывает Composio на этом же экране. Внутри Composio переход к настройке конкретного сервиса сохраняется.

## Linear: подтверждённая причина текущей недоступности

В реальном UI нажата только загрузка списка — без preview, commit или изменения аккаунтов. Сервер вернул: «Подключите общий аккаунт Linear в Composio.» В linearTransport этот ответ соответствует not_connected; composio_mcp ищет ACTIVE-подключение toolkit linear для taskflow:<ownerId>. Значит этот канал не нашёл активного общего аккаунта. MCP Linear данного чата — отдельный канал.

Для восстановления нужно авторизовать общий аккаунт Linear в Composio и повторить загрузку. Авторизация и перенос задач не выполнялись. Полнота переноса проектов, документов и зависимостей этим результатом не подтверждена.
