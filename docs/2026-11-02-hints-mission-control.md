# Подсказки для контракта миссии

Дата: 02.11.2026
Реестр: `LOCK-HINTS-MISSION-CONTROL` (`IN_PROGRESS` → `REVIEW`)

## Что это

Режим подсказок (владелец 16.10.2026) — пошаговое обучение поверх настоящего
интерфейса. Схема утверждена: якорь `.hintAnchor("…")` на элементе + сценарий в
`HintScenarios` + запись в `HintScenarios.all`. Правило владельца: **новая функция —
новая подсказка**.

Тумблер живёт в **Настройки → «Подсказки»** (`HintsSettingsSection`): включает режим
и показывает список сценариев с кнопкой «Пройти» / «Пройти заново». Состояние
(включён, какие сценарии пройдены) хранится в **UserDefaults на устройстве** — сервер
не участвует, поэтому на новом устройстве подсказки придётся включить заново.

## Сценарии

**«Контракт миссии»** (новый, `mission-control`) — три шага:

1. **Координация** → где искать: в меню задачи «Координация», внизу раздел
   «Контракт миссии».
2. **Раздел контракта** → сама строка «Mission Control»: что видно и что раздел не
   меняет (это чтение).
3. **Экран Mission Control** → что показывает: итог (пройдено / провалено / не
   проверяется вживую), критерии с номером и чем проверяются, дыры в покрытии,
   журнал.

**«Почему шаг ждёт»** (существующий, `task-coordination`) — добавлен второй шаг
**«Контракт миссии»**: он лежит в том же экране и объясняет, почему шаг может не
закрыться — непроверенный критерий не даёт закрыться задаче.

## Проверки

### Выполнено

1. **Логика сценариев — без симулятора, все проверки зелёные.** `HintModels` /
   `HintScenarios` / `HintCenter` — чистые Foundation, собраны `swiftc` для macOS с
   отдельным харнесом (вне репозитория): переходы нового сценария (координация →
   раздел → экран), второй шаг координации, **связность всех сценариев реестра**
   (у каждого есть стартовый шаг, каждый `next` и каждая ветка ведут в
   существующий шаг), уникальность id, наличие нового сценария в общем списке.
2. **Сторож дизайн-системы** — `python3 Tools/design-system-guard.py --folder` → чисто.
3. **Сторож заголовков экранов** — `python3 Tools/screen-heading-guard.py` → чисто.
4. **Сборка generic iOS** — `xcodegen generate` + `xcodebuild -destination
   'generic/platform=iOS' build CODE_SIGNING_ALLOWED=NO` → BUILD SUCCEEDED.

### Не выполнено и почему

- **Юнит-тесты `Tests/HintCenterTests.swift` написаны и компилируются, но не
  запускались:** цель `bundle.unit-test` для iOS требует симулятора, а по прямому
  указанию владельца от 25.10.2026 симулятор не трогаем без отдельного поручения.
  Логика сценариев проверена эквивалентным способом без симулятора (п. 1).
- **Сборка тестовых бандлов целиком** падает на чужом
  `Tests/Today/TodayFilterEngineTests.swift` — файл не менялся с первого коммита,
  поломка уже в `main`.
- **Симулятор, установка на iPhone, UI-тесты, визуальная приёмка** — не
  выполнялись; внешний вид и пошаговость подсказок оценивает владелец.

## Открыто к решению владельца

- **Тумблер по умолчанию выключен** (`UserDefaults.bool` → false). Включается в
  Настройках → «Подсказки». На новом устройстве включается заново. Сделать
  включённым по умолчанию?
- **Автостарт** (`tryAutoStart`) поднимает первый непройденный сценарий, чей якорь
  появился на экране. Новый сценарий начинается с координации — то есть подсказка
  про миссию покажется, когда владелец откроет «Координацию». Порядок в
  `HintScenarios.all` влияет на то, какой сценарий поднимется первым.
