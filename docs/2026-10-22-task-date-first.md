# Даты в списках — первыми

22.10.2026 · реестр: `LOCK-TASK-DATE-FIRST-20261022`

## Задача

Владелец 22.10.2026: «даты в списках поставь самыми первыми по счету что бы они
были в одном месте все, т.к. это элемент присутствующий по умолчанию во всех
задачах в отличии от других меток этой строчки».

## Результат

В строке задачи дата теперь идёт первой — обе даты (срок и дата заведения) стоят
в начале метро-ряда, одна колонка на всех списках.

| Строка | Файл | Экраны |
| --- | --- | --- |
| `TFTaskRow` | `Sources/DesignSystem/Components/TFTaskRow.swift` | «Предстоящее» (день), «Поиск», «Линейные задачи» |
| `TodayTaskRow` | `Sources/Features/Today/TodayTaskRow.swift` | Планирование → «Сегодня», «Ждут вас», «Входящие» |
| `DirectoryTaskRow` | `Sources/Features/Directory/Support/DirectoryTaskRow.swift` | «Все задачи», «Проекты», «Архив», «Активность» |
| строка «Задачи метки» | `Sources/Features/Directory/LabelTasksScreen.swift` | Метки → задачи метки |
| `AgentWorkTaskRow` | `Sources/Features/Chat/AgentWorkTaskRow.swift` | строка «Работа агентов» (файл сейчас не вызывается — см. ниже) |

Порядок метро-ряда стал одинаковым везде:

```
дата (срок) → дата заведения → показатели структуры → статус агента → проект → метки
```

## Что сделано

1. **Дата (срок) — первой.** Раньше первой шла плашка структуры (приоритет,
   подзадачи, дочерние) — она есть не у всех задач, из-за чего дата сдвигалась
   по строке и колонки не было.
2. **Дата заведения — сразу за ней.** Пиксельная метка
   `[22.10.2026 - 14:07]` (LOCK-TASK-CREATED-STAMP) стояла в четырёх разных
   местах: после статуса, после проекта, после плашек меток, второй. Теперь она
   всегда вторая — обе даты в одном месте, независимо от списка.
3. **Дата не сжимается.** Сроку и дате заведения выдан `layoutPriority(1)` —
   раньше дата могла уехать в конец строки и обрезаться; теперь она первая и
   читается целиком, а ужимаются метки (у них `layoutPriority(-1)`).

Сдвиг — только порядок элементов. Ни одна величина, ни один текст, ни одно
правило не менялись: те же компоненты, те же данные, те же цвета.

## Ограничения

- **Колонка по левому краю, а не по ширине.** Плашки дат разной длины
  («[22.10.2026 - 14:07]», «Завтра, 14:00»), текст в них не выровнен по
  вертикали внутри плашки. Единую ширину плашки владелец не просил — это
  отдельная правка.
- **`AgentWorkTaskRow.swift` сейчас не вызывается** ни на одном экране:
  «Работа агентов» (`AgentWorkScreen.swift:125`) рисует `DirectoryTaskRow`.
  Файл оставлен в том же порядке, чтобы при возврате списка в жизнь дата
  была первой сразу. Удаление мёртвого файла — отдельное решение.
- **`UpcomingListView` / `UpcomingTaskRow`** тоже не вызываются (строка
  «Предстоящее» идёт через `TFTaskRow`), в них правка не делалась.

## Сверх задачи

- `layoutPriority(1)` для даты — добавлен, чтобы дата не обрезалась: без
  этого «первой» она была бы только по порядку, а не по читаемости.
- Дата заведения переехала из конца метки в начало — это вторая дата строки,
  иначе «даты в одном месте» не выполняется.
