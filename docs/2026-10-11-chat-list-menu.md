# Меню списка чатов

Основной экран всегда показывает личные чаты, без переключателя разделов. Чаты проектов открываются отдельным экраном из меню с троеточием. Действия создания чата и группы проекта сохранены. Счётчик непрочитанных проектов показывается в пункте меню. XCUITest подтвердил отсутствие вкладок, открытие проектов и возврат. Кадры до/после сохранены.
