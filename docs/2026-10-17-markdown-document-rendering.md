# Предпросмотр Markdown-документов

## Что изменилось

- Добавлен read-only предпросмотр документа из секции «Итог» задачи. Он загружает исходное Markdown через `GET /notes/:id?format=markdown` и рисует его в памяти.
- Тап по названию документа по-прежнему открывает редактор. Сохранение, хранение заметки и экспорт «Сохранить на телефон» не менялись.
- Markdown и простые JSON-блоки (`text`, `heading`, `list`, `table`) теперь используют общий набор блоков и компонентов. JSON-графики, статусы, прогресс, схемы, отчёты и передачи остались типизированными JSON-компонентами.
- Inline-текст оставлен светлым; жирное начертание выделяется весом шрифта и небольшой разницей яркости. Заголовки крупнее обычного текста, ссылки окрашены в фирменный красный.

## Границы

Сохранённые заметки и скачиваемые файлы остаются в исходном формате. Экспорт не использует представление предпросмотра. Автоматической конвертации и переписывания документов нет.
