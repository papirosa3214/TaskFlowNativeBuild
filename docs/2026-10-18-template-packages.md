# Шаблоны командного плана — 18.10.2026

Реализован согласованный каталог из десяти шаблонов. К пяти прежним пунктам iOS добавлены продуктовая фича, баг/регрессия, UX-концепция, API-интеграция и аудит. Три новых серверных графа — UX, API и аудит. Manual остаётся индивидуальным планом по существующим подзадачам.

Сервер сохраняет версию пакета, инструкции, ожидаемые результаты и кандидатов навыков в узлах конкретного плана. SDK получает задание текущего этапа и только его набор; JEV может уточнить набор. Общие настройки JEV не изменены. Продуктовая фича и баг при явном выборе имеют полный стандарт без нового опроса флагов. Аудит не запускает исправления.

Проверено: iOS BUILD SUCCEEDED, 13 HintCenterTests, 0 отклонений скана оформления. Все десять идентификаторов меню сверены с серверным каталогом. Серверные API/SDK/миграция и runtime проверены отдельными изолированными тестами. Доступность 84 навыков восьми ролей подтверждена SDK; это не доказательство их применения живой моделью.

Полная матрица «шаблон → этап → навыки», ограничения и инвентаризация SHA256 находятся в серверном репозитории: docs/2026-10-18-template-packages.md и docs/2026-10-18-template-skill-inventory.json.

Результат работы — коммиты и push Gitea обоих репозиториев. Сервер и iPhone не обновлялись: новые профили требуют серверной миграции 154, после чего можно обновлять клиент. Физическая/UI-приёмка нового меню не заявляется. Чужие правки Task.swift и чата не включены в коммит.

Серверный коммит: `c967e66a` (taskflow-server).
