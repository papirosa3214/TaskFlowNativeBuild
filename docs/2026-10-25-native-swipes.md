# Системные свайпы списков — 25.10.2026

## Поручение

Отменить предыдущую правку кнопок рутины. Проекты и задачи во всех списках должны использовать отрисовку Apple, как «Мои рутины»: системный жест, сдвигаемая поверхность строки, кнопки. Дополнение владельца: у кнопок свайпа только иконки, без видимых надписей.

## Результат реализации

- Предыдущая правка отменена отдельным коммитом f727184.
- Проекты, задачи проекта/общего списка, архив, история выполнения, работа агентов и прежний список предстоящих переведены на SwiftUI List, `.listStyle(.plain)` и `.swipeActions`.
- Список планирования уже использовал List; убрана прозрачная подложка задач, препятствовавшая стандартной поверхности строки.
- Ручные панели, offset, пороги, резина, анимации и HorizontalPan из компонентов списочных строк удалены. Системным свайп-кнопкам не задаются собственные фон, форма, размер и шрифт.
- По дополнительному указанию владельца сохранены цвета через штатный tint: «Изменить» — tfSwipeEdit (синий), завершение/принятие/запуск/восстановление задач — tfGreen, архив/удаление — tfSwipeDelete (красный); возобновление рутины — tfGreen, пауза остаётся серой. Tint не меняет системную геометрию.
- Подписи убраны из всех существующих swipeActions, включая рутины, память и отвязку связанных задач. Полные названия остаются в accessibilityLabel.
- Обработчики действий, выбор контекстного действия, порядок задач и подтверждения безвозвратного удаления сохранены. Полный свайп не выполняет действия автоматически там, где раньше он был отключён.
- Используется List, поддерживаемый всеми целевыми версиями iOS; новый iOS 27 swipeActionsContainer не требуется. Apple [описывает различие List и произвольного контейнера](https://developer.apple.com/documentation/swiftui/view/swipeactionscontainer%28%29). За серую поверхность отвечает сам List, имитаций в коде нет.
