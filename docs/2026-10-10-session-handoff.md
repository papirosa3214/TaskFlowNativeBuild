## Что помнить

- **5180** — веб TaskFlow, **8080** — RAGFlow (к TaskFlow отношения не
  имеет), **3001** — API прод.
- **RAGFlow — отдельная среда, в проекте TaskFlow не упоминается вообще.**
  «База знаний» — всегда внутренняя база TaskFlow.
- Сервер работает из `dist/`, не из `src/`. После вливания: `tsc -p
  tsconfig.json`, затем `systemctl --user restart taskflow-server`.
  **Без пересборки коммит в main не действует.**
- Рестарт рвёт работающие ролей: перед рестартом `taskflow_status` —
  «в работе» должно быть пусто.
- В vitest на сервере нужен node из nvm `v22.23.1`; системный `v18` даёт
  `styleText` export error.
- **Приватные проекты фильтруются на уровне API. При прямом чтении
  `taskflow.db` фильтр ставить самому.**
- В дереве iOS рядом лежат чужие незакоммиченные правки
  (`IntegrationsScreen.swift`, `CollaborationPlanView.swift`,
  `TaskFamilyNavigation.swift`) — не трогать.
