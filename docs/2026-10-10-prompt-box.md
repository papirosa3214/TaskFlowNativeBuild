# Экспериментальное поле ввода чата

Образец: https://21st.dev/@jahed/components/ai-prompt-box . Реализация SwiftUI по доступному визуальному образцу, исходник React закрыт на сайте.

## Результат

Тёмная панель с текстом сверху, вложениями и режимом работы снизу, белой круглой кнопкой микрофона/отправки. Запись: красная рамка, таймер сверху, настоящая волна по уровню микрофона, остановка справа снизу. Существующие удержание для записи, расшифровка, предварительное прослушивание и ручная отправка сохранены. Предварительное прослушивание использует прежнее оформление.

## Возврат

Меню вложений (скрепка в новом виде, плюс в прежнем) → выключить «Экспериментальное поле». Выбор хранится локально в `chat.experimentalPromptBox`; по умолчанию новый вариант включён. Прежние ветви полностью сохранены в том же компоненте. Отдельный коммит позволяет также откатить эксперимент целиком.
