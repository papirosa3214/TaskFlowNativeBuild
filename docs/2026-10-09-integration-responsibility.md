# Ответственный за интеграцию

В «Сведениях» карточки добавлено отдельное поле с выбором участника команды. Автоматически предлагается оркестратор, иначе архитектор, иначе единственный исполнитель. При нескольких исполнителях без этих ролей требуется конкретный выбор. Явный вариант «Не требуется» — для работ без правок репозитория. Свободного ввода нет.

Правила открываются неброской кнопкой вопросительного знака; постоянной поясняющей подписи нет. При попытке запуска без ответственного поле и ошибка красные, раздел Сведения раскрывается. Сохранение черновика разрешено.

Сервер хранит tasks.integration_mode и integration_owner_id. Для общей ветки ответственность хранится на корневой карточке, кандидаты — участники действующих планов её карточек. GET/PATCH /api/tasks/:id/integration-responsibility возвращает назначение и сохраняет выбор. Проверка запуска находится до создания слотов, внутри утверждения плана/ветки; источник создания карточки не влияет на проверку. Сдача результатов и ревью не менялись. Назначение включено в стартовое задание ролей.
