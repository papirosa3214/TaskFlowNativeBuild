# Карточки и чат — 03.10.2026

## Изменения

- Указатель «Общий план и запуск — в корневой задаче» использует фон карточки вместо системной подложки строки List.
- Аватары сообщений увеличены с 20 до 32 pt; у плоского ответа агента тоже виден автор.
- Собственные голосовые используют адаптивный цвет текста, волны, длительности и заголовка. Обычные текстовые сообщения уже имели корректный адаптивный цвет.
- У завершённых ответов агента есть реакция, копирование и экспорт исходного текста в Markdown через системное меню iPhone. Повторная такая же реакция снимается; сервер хранит одну реакцию участника на сообщение.
- Превью Секретаря и история читаются из одной комнаты `/api/chats`, старый owner-канал больше не используется для превью. Версия запроса не позволяет старому ответу перезаписать свежий список. При одинаковой секунде отправки сервер выбирает последнее сообщение по rowid, как история.
- При движении карточек тень применяется к собранной поверхности: внутренние полоски и текст не получают отдельную тень.
- При создании плана отсутствующий ответственный карточки назначается по конечному рабочему узлу, исключая критика. Для корня ветки — Архитектор. Ручное назначение сохраняется. Неоднозначный итог требует этапа сборки, произвольная роль не выбирается.
