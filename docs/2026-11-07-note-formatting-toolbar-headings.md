# Панель заметок и шрифт заголовков — 07.11.2026

## Поручение
Вернуть панель форматирования заметок, корректно отображать разметку, установить причину одинакового размера заголовков и обычного текста. Серверный разбор сохраняется.

## История причины
`3f41d572` от 17.10.2026 увеличивал жирное выделение в обычном тексте, а заголовки намеренно оставлял со своим размером (`liftBold: false`).

Регрессия появилась в `06ffbda95a246a236083db8f045b7a0d9cce01cb` от 04.11.2026 (автор коммита в Git — Pi Agent; сообщение: возврат из стэша 03.11 настроек шрифта и общего оформления). В readableText каждому не-кодовому и не-увеличенному жирному фрагменту стали задавать `.font(.tfChat(.body))`, в том числе внутри заголовков. Этот локальный font перебивал наружный font заголовка. Отдельное решение владельца выровнять размеры из истории не следует.

Панель исчезла раньше, в `e67bd817` от 22.10.2026: редактирование заметки переведено на исходный Markdown с обычным TextEditor. Это отдельное изменение, не следствие переноса парсера на сервер.

## Изменения
- Заголовок передаёт собственный font внутрь каждого фрагмента. Обычный текст, жирное выделение и код сохраняют свои группы настроек; код внутри заголовка сохраняет размер заголовка и моноширинное начертание.
- Марка highlight отображается с фоном маркера из существующего цвета tfYellow, как в блочном редакторе.
- TFMarkdownSourceEditor использует UITextView с прежней MarkdownKeyboardAccessoryBar: жирное, курсив, подчёркивание, зачёркивание, маркер, inline-код, ссылка, H1/H2/H3, списки, checkbox, цитата, блок кода, разделитель, диктовка, скрытие клавиатуры.
- Панель меняет исходник и UTF-16-выделение; не строит документ на телефоне. Сохраняются выделение, undo, ввод с составными символами и серверное автосохранение. Активные кнопки отслеживают контекст выделения.
- H1–H3 ставятся в начало строки с пробелом, кодовые ограждения — отдельными строками. Переключение не дублирует одинаковые маркеры. Ссылка оставляет URL выделенным для ввода; пустое выделение получает редактируемую подпись.
- Сервер поддерживает `<u>…</u>`, обратный экспорт underline, `***жирный курсив***` и вложенные разные пометки. Интерпретация документа остаётся в существующем серверном конвертере.
