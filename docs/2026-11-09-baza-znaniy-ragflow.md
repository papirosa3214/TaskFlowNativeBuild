## Грабли

- Перезапуск сервера рвёт живые ходы ролей. 09.11.2026 проверял только
  `role_run_jobs` и срубил два хода (`chat_message_queue.status='picked'`).
  Правильная проверка — `chat_message_queue` (`pending`/`picked`) и
  `chat_live_drafts` (`running`).
- Миграции применяются в `buildApp()`, не в `db.ts`: тест обязан вызвать
  `await buildApp()`, иначе нет таблиц.
- Тест не может выдать себе `role_key`: триггеры `users_role_key_update_guard`
  требуют `type='ai'`, `role='agent'`, `is_system_bot=1`, `id='role_'||role_key`.
  Поведение ролей проверяется юнит-тестами, HTTP — учёткой владельца.
- `JSONValue` в iOS не имеет кейса `.int` — позиции разделов уходят `.number`.
- `TFListRow` принимает `trailing: AnyView?`, а не замыкание.
- Сторож дизайн-системы: шторки — `tfSheet`, тумблер — `TFToggle`, загрузка —
  `TFLoading`; голые `.sheet`/`Toggle`/`ProgressView` в новых файлах не проходят.
- На main лежал сломанный `AIUsageScreen.chartSection` (два выражения в теле без
  контейнера — `some View` не выводился), сборка под телефон падала. Починено
  в `7f2cf4ad` минимальной обёрткой в `VStack`.
