# Карточки назначений в личной комнате роли (клиент)

Дата: 08.11.2026. Серверная часть — `docs/2026-11-08-chat-child-sessions.md` в
репозитории TrackFlow (New-Todoist).

## Что появилось

- `ChatChildAssignment` — карточка назначения из `GET /api/chats/:id/children`:
  комната задачи, слот, статус («Назначено», «Передано сессии», «Ответ получен»,
  «Ждёт решения», «Ошибка»), номер попытки.
- `ChatChildAssignmentsStrip` — полоса над лентой личной комнаты. Строки —
  системным `TFListRow`, без собственных подложек и цветов; тап открывает
  общую комнату задачи (`talk_chat_id`), где и идёт разговор.
- В `RoleChatRoomScreen` полоса включена только для личной комнаты роли
  (`roomKind == "personal"`). В комнате задачи её нет: там карточки не нужны,
  разговор и так в ней.

## Почему карточка живёт не в ленте сообщений

Спецификация §5: сервер должен отделить **отображаемые** карточки от **входа
модели**, и одной проверки `message_type='system'` для этого мало. На сервере
карточка лежит в отдельной таблице `chat_child_sessions`, то есть в истории
переписки её нет вовсе. Клиент рисует её отдельной полосой и не смешивает с
сообщениями: лента, выжимки, кеш и непрочитанные её не видят.
