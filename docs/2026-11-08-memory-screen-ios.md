# Память TaskFlow в «Интеграциях»

Дата: 08.11.2026. Владелец: «в приложении на айфоне, там где у нас интеграция, добавь
интеграцию TaskFlow именно Mnemosyne… я хочу видеть количество раз по конкретным
агентам, кто туда обращается, и мне должен быть окно ввода, чтобы я мог сам запрашивать
информацию и смотреть, что там за барахло валяется».

## Что видно на экране

«Интеграции» → «Подключения TaskFlow» → «Память TaskFlow» (`integrations.taskflowMemory`).

- **Кто обращается.** По агенту: имя, «80 записей · 214 прочтений», справа
  «12 обращений» (журнал обращений с 08.11.2026) или «не спрашивал». Роли, которые
  ещё не спрашивали, тоже в списке — иначе «не видно» читается как «нет памяти».
- **Что лежит.** Строка банков и поле поиска в шапке (`searchable`, системное).
  Пустой запрос — свежее сверху; с запросом — поиск по всем банкам Mnemosyne,
  найденное карточками с названием банка («Командная память», «Роль: builder»).

## Сервер

`GET /api/memory/agents` → `{agents, banks}`; `GET /api/memory/browse?q=&limit=` →
`{items, banks}`. Журнал обращений — миграция `212_memory_access_log`; пишется в
`recall` (в `finally`, поэтому упавший поиск тоже виден) и в ручном поиске владельца
(`kind=owner`). Серверная часть описана в `New-Todoist/docs/2026-11-08-memory-watch.md`.
