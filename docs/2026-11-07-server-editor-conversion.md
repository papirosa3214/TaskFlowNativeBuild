# Преобразование ввода редактора на сервере — 07.11.2026

## Поручение
Вынести оставшийся разбор вводимого Markdown из редакторов iOS на сервер, сохранить возможность ввода и редактирования.

## Что изменено
- Используется существующий `POST /api/notes/markdown-to-doc`. Он возвращает TipTap, не создаёт заметок и не сохраняет текст в БД.
- APIClient вызывает этот endpoint, модель редактора принимает только готовую структуру через строгий `NoteDocument.fromServer`.
- Сеттеры названия, описания и комментария хранят исходный ввод буквально; MarkdownParser из них удалён. Импорт из диктовки и ответ AI преобразуются через сервер.
- Пока сервер отвечает, введённый текст остаётся в поле. При сетевой ошибке он не теряется; показывается ошибка. Поздний/отменённый запрос не заменяет новые правки. Снимок блоков включает их устойчивые UUID, а не только совпадение строк.
- Поля AI и новые шаги сначала целиком преобразуются, затем применяются; ошибка одного преобразования не оставляет половину обновлённой формы.
- Новые шаги хранят собственные редактируемые блоки, без повторного разбора строки при отрисовке. Сохраняются оформление, ID черновика и обычное редактирование текста.
- Существующие шаги получают `title_document` от сервера. Сериализация/декодирование ApiSubtask сохраняют это поле. В режиме редактора отсутствие структуры показывает ошибку вместо локального парсинга.
- Заметки уже преобразуют Markdown при серверном сохранении; их локального разбора после предыдущего изменения нет.

## Проверки
- `Tools/test_editor_server_conversion.py`: RED на прежних сеттерах → GREEN. Исполняются реальные тела сеттеров, проверяются отсутствие вызовов парсера и сохранение буквального исходника.
- `Tools/test_editor_server_async.py`: компиляция реальных методов модели, APIClient и SubtaskDraft на macOS. Проверены путь/POST/тело существующего endpoint, серверные marks, задержанный ответ после правки, сетевой сбой, точный исходник, ID/блоки черновика, атомарность импорта AI при успехе/сбое.
- `Tools/test_server_document.py`: сохранность серверных документов и таблиц, проверка тихого обновления карточки; контур обновлён под сохранение исходника названия.
- Сервер: `test/taskBatch.test.ts --maxWorkers=4` — 7 PASS. Новый тест документа шага прошёл RED → GREEN; проверено, что преобразование возвращает таблицу/marks без создания заметок.
- Обновлён транспортный fixture `Tests/TaskStructureTests.swift` под серверное преобразование. Сам XCTest требует iOS-контур и не запускался.
- Только синтаксический разбор изменённых Swift-файлов, design-system guard, diff check. Сборка приложения, симулятор, UI-тесты и установка не выполнялись.
