# Дозагрузка старых сообщений в ленте чата снова работает — 08.11.2026

## Что заметил владелец

«Первично отображаются последние 10 сообщений, при прокрутке происходит дозагруз…
а сейчас что-то нет у этого дозагруза, они просто как бы удалились и все».

## Причина

Дорисовку старых сообщений запускал `onAppear` однопиксельной полоски вверху
ленты (`Sources/Features/Roles/RoleChatRoomScreen.swift`, до правки :1380-1391):

```swift
if self.visibleMessages.count > feedWindow {
    Color.clear.frame(height: 1)
        .onAppear {
            guard chatScrollPhase != .idle else { return }
            …
            feedWindow += RoleChatFeedWindow.step
        }
}
```

07.11.2026 коммит `547c078f` сделал две вещи одновременно:

1. добавил `guard chatScrollPhase != .idle` — чтобы полоска не подгружала старые
   сообщения сама при открытии короткого чата и не увозила ленту от низа;
2. убрал `LazyVStack` в пользу обычного `VStack` (ленивая лента ошибалась в
   оценке высот, см. комментарий у `ForEach(orderedFeed)`).

В обычном `VStack` все строки монтируются сразу, в том же кадре, что и полоска.
`onAppear` срабатывает ровно один раз — при вставке полоски в иерархию, в фазе
`.idle`, когда владелец ещё ничего не листал. Guard из пункта 1 её отбрасывал.
Второй раз событие не приходило никогда: полоска не «появляется» заново, лента
не ленивая. Сообщения никто не удалял — они просто остаются скрытыми за окном
`suffix(feedWindow)`.

## Что сделано

- Решение «дорисовать ещё десять» вынесено в чистую функцию —
  `Sources/Features/Roles/RoleChatFeedWindow.swift`:
  `shouldGrow(hidden:nearTop:scrolling:)` и `grown(window:)`, шаг 10.
- Триггер заменён: вместо однократного `onAppear` полоски — наблюдатель
  геометрии `.onScrollGeometryChange(for: Bool.self)` с порогом 300 pt от верха
  содержимого. Геометрия меняется на каждый сдвиг, поэтому дозагруз срабатывает
  столько раз, сколько владелец листает вверх.
- Условие «только под рукой владельца» сохранено: фаза прокрутки должна быть
  `tracking`, `interacting` или `decelerating`. Открытие короткого чата ленту
  по-прежнему не двигает (решение 07.11.2026 не отменено).
- Лента не прыгает: перед расширением окна запоминается верхний элемент, после
  расширения он же ставится в верх видимой области (`scrollTo(id:anchor: .top)`).
- Полоска-триггер высотой 1 pt удалена; `enum RoleChatFeedWindow` из конца
  `RoleChatRoomScreen.swift` переехал в собственный файл.
