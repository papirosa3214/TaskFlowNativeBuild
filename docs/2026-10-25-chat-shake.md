# Чат с ролью: лента шаталась вверх-вниз, пока идёт ответ агента

Дата: 25.10.2026. Исходник: `/Users/max/Проекты/TaskFlowNativeBuild`, main.
Правки: `Sources/Core/Models/RoleChat.swift` (pacer), `Sources/Features/Chat/RoleActionGroup.swift`,
`Sources/Features/Chat/RoleLiveTurnView.swift` (раскладка живого хода),
`Sources/Features/Chat/RoleChatsScreen.swift` (отладочный стенд, только DEBUG).

## Запрос владельца

«Почему, когда я жду ответа от агента, чат шатается вверх-вниз».

## Коротко

Лента держится за нижний край (`defaultScrollAnchor(.bottom, for: .sizeChanges)`), поэтому
любое изменение высоты живого пузыря двигает всю переписку. Высота менялась дважды:

1. **Проявленные шаги и размышления терялись при сдвиге индексов.** Сервер в снимке
   прячет законченное пустое размышление (`server/src/runtime/chatLiveTurn.ts`,
   `snapshot()`), и индексы пунктов сдвигаются. Pacer помнил проявленные действия по
   индексу (`revealedActions: Set<Int>`) — после сдвига проявленное действие считалось
   «не тем» и обрезалось. Видимый список терял хвост, вторая полоса с превью исчезала
   совсем, живой пузырь схлопывался на ~44 pt, лента прыгала вниз — и тут же обратно,
   как только pacer проявлял пункты заново (по одному в 0,4 с).
2. **Форма живого пузыря менялась по ходу.** Одно действие рисовалось голой строкой, два и
   больше — полосой «Действия» с превью текущего шага; когда приходил текст ответа,
   полоса переставала быть последней и превью под ней исчезало. Каждая такая перемена —
   это изменение высоты, а значит скачок ленты.

## Замер

Стенд (только DEBUG): длинная переписка на 300 сообщений и идущий ход роли, снимки
приходят каждые 150 мс, как их шлёт сервер. Фазы повторяют боевые: размышление с
растущим текстом → шаги → текст ответа в середине хода → снова шаги → конец хода.

Запись экрана симулятора (iPhone Air, iOS 27.0), положение переписки меряется по
профилю строк и целочисленному сдвигу между соседними кадрами, масштаб 1/3 —
один пункт равен одному пикселю.

| | скачки ленты | из них вниз | смен направления | амплитуда |
|---|---|---|---|---|
| до | 8 крупных (11 смен направления) | **2: +44 pt и +43 pt** | 11 | 50 pt |
| после | 5 крупных, все вверх | **0** | — | 56 pt |

Прыжки вниз — это и есть «шатание»: лента уезжала вниз и возвращалась обратно.
После правки крупных скачков вниз не осталось: лента только поднимается, как при
обычном росте ответа.

## Что сделано

| Файл | Правка |
|---|---|
| `Sources/Core/Models/RoleChat.swift` | `RoleLiveTextPacer`: проявленные действия помнятся по id (`step:`/`thinking:`), а не по индексу; текст узнаётся по порядку среди текстовых пунктов, а не по индексу. Сдвиг индексов в снимке больше не обрезает видимый список |
| `Sources/Features/Chat/RoleActionGroup.swift` | `RoleLiveSegment.split(..., groupsSingleAction:)`: одиночное действие во время хода тоже полосой; `RoleActionGroup.showsPreview`: превью под полосой есть у каждой полосы, пока идёт ход |
| `Sources/Features/Chat/RoleLiveTurnView.swift` | `RoleLiveItemsList.showsActionPreview` — постоянная форма живого пузыря; заголовок шага в одну строку, чтобы строка не меняла высоту |
| `Sources/Features/Chat/RoleChatsScreen.swift` | отладочный стенд шатания (`TASKFLOW_CHAT_SHAKE_PREVIEW=1`), только DEBUG |

Вид в истории (у законченного ответа) не изменён: полоса «Действия» без превью, как было.
