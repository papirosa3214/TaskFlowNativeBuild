# «Входящие»: адрес запроса с двойным `/api`

Дата: 29.10.2026
Реестр: `LOCK-ATTENTION-API-PATH-20261029` (REVIEW)

## Поручение

Владелец, 29.10.2026:

> «У меня просто в настройках уже есть панель навигационная… У меня почему-то
> во входящих… ошибка возникает. Сервер не знает такого запроса. Get API. API.
> Опять двойное API… Вот надо это убрать, и будет всё хорошо.»

## Причина

`APIClient` сам добавляет префикс `/api` к пути запроса. На экране «Входящие»
путь был записан как `"/api/attention"`, и адрес получался
`/api/api/attention` — сервер такого маршрута не знает.

Правка от 28.10.2026 (`ea678def`) это уже чинила, но правка 29.10.2026
(`b5cce4a6`, переделка «Входящих» в три статуса) вернула префикс обратно.

## Что сделано

- `Sources/Core/Networking/APIEndpoint.swift` (новый) — адрес эндпоинта в
  одном месте: `APIEndpoint.url(path, base:)` добавляет `/api` ровно один раз.
  Путь «Входящих» — `APIEndpoint.attention.list` (`"/attention"`, без
  префикса).
- `Sources/Core/Networking/APIClient.swift` — сборка адреса запроса и загрузки
  идёт через `APIEndpoint.url`.
- `Sources/Features/Attention/AttentionScreen.swift` — запрос списка «Входящих»
  идёт по `APIEndpoint.attention.list`.
