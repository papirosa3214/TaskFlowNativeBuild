# Стиль каждой группы шрифта и обновление образца

В настройках раньше был только общий стиль для приложения и отдельно чата.
У пяти групп приложения и шести групп чата были только регуляторы размера.
Образец читал UserDefaults, но body не читал revision изменения размера.

Добавлен выбор гарнитуры под каждой группой. Индивидуальный выбор хранится
отдельно от общего и остальных групп; «По общему стилю» сбрасывает override.
Существующие настройки сохранены. Без override код чата остаётся системным
моноширинным, как раньше; для него также доступен индивидуальный выбор.

Образцы приложения/чата и семантические модификаторы шрифта используют
настройку своей группы. Экран и модификаторы явно читают revision; изменение
размера или стиля обновляет образец без выхода/повторного открытия экрана.
Скилл SwiftUI использован для проверки зависимости View от текущего состояния;
identity корня и навигация ради обновления не пересоздаются.

Проверки: host Swift preferences RED (отсутствовал group API) → GREEN:
наследование, независимость групп/контекстов, сброс override, код чата.
Design guard, Swift parse, diff. Без UI-тестов и симулятора. Визуальная
приёмка размера/начертания на устройстве остаётся за владельцем.
