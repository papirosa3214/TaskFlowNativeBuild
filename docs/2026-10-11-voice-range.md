# Диапазон визуализации речи — 11.10.2026

Рабочий образец владельца: голосовое поле Codex, разные пики внутри фраз, точки в паузах; сохранить тёмно-красный→ярко-красный по высоте.

Причина: прежняя функция превращала дБ в progress с степенью0.6, сильно поднимала тихие уровни и сжимала различия; спад с коэффициентом0.12 на40мс удерживал высоту. История была настоящей, но такая шкала сглаживала детали речи.

Теперь дБ преобразуются в амплитуду (10^(дБ/20)). Используются фиксированные границы -55…-6дБ и sqrt для видимости тихой речи, без нормализации каждого окна по его максимуму. Средняя/пиковая мощность сохраняют веса65/35. Отклик0.85, спад0.65 на40мс, примерно0.1с до затухания. Полный диапазон0…1 доступен; цвета и общий компонент обоих режимов сохранены.

DEBUG preview читает secretary-voice-kore.m4a, RMS и peak по40мс и применяет ту же функцию. Аудиообразец воспроизводится в данных один раз, повторяющийся искусственный рисунок удалён. Это аудиофайл образца голоса из приложения, не запись владельца с физического микрофона.
