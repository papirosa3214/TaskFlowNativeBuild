# Два режима работы ролей TaskFlow

Статус: договорённость утверждена Максимом 22.10.2026. Этот документ фиксирует требуемое поведение; реализация и выкладка не выполнены в рамках этой фиксации.

## Выбор владельца

Явный переключатель: **«В чате / По карточке»**. Способ выполнения выбирает владелец; агент не переключает его самостоятельно. Выбор действует на весь разговор, включая голос и уточнения во время работы.

## В чате

Роль выполняет поручение прямо в разговоре до результата: исследует, пишет код, исправляет ошибки, готовит документы. Сообщает ход работы, принимает уточнения во время выполнения, возвращает результат и файлы в переписку.

Карточка не является условием выполнения. Долгая или сложная работа сама по себе не требует перехода в карточку. Создавать карточки можно только по прямой команде владельца. Навязывать оформление карточки вместо выполнения поручения нельзя.

## По карточке

Работа привязана к созданной или выбранной карточке: условия, этапы, отчёт и приёмка ведутся по установленному процессу задачи. Результат сохраняется в карточке.

## Обеспечение режима

Обе формы работы сохраняют возможности и личность роли. Сервер должен явно учитывать выбранный режим: при работе в чате не выдавать инструменты создания карточек и требования карточного процесса. Одного указания в промпте недостаточно.

Команда владельца «Оформить как карточку» переносит согласованные договорённости из разговора в задачу. Она является явным разрешением на создание карточки.

## Критерии будущей проверки

- В режиме «В чате» поручение выполняется до результата без создания карточки и требования сначала её завести.
- Уточнение и голосовой запрос сохраняют выбранный режим.
- Длительность работы не меняет режим автоматически.
- В режиме «По карточке» результат проходит установленный процесс задачи.
- Переход из чата в карточку выполняется по прямой команде владельца.
