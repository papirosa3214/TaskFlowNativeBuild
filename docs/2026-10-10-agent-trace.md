# Ход работы агента в окне графа

SwiftUI-адаптация идеи [Agent Trace от NIMA MZ](https://21st.dev/@n1m4mz/components/agent-trace). React/shadcn в нативный проект не устанавливались; реализован отдельный SwiftUI-компонент.

## Поведение
В PlanStepDetailSheet добавлена секция «Ход работы», доступная также после завершения шага. Запуски выбираются по дате; ползунок показывает состояние действий в выбранный момент: ожидание, выполнение, завершение, ошибка. «Сейчас» возвращает к последнему полученному снимку. Данные изолированы по task_id и subtask_id, снимки объединяются по run_id и id действия. События activity без длительности отображаются отдельными отметками; границы такого запуска неизвестны. Действия без времени начала не получают выдуманных интервалов.

## История и энергия
Сохраняются только полученные этим устройством данные. Серверный /live хранит временный снимок, полного долговременного архива в этом API нет. Запуски, не полученные приложением, задним числом не восстанавливаются. Локальный архив ограничен 100 контекстами, 10 запусками в контексте и 300 действиями в запуске. Сохранение при завершении, закрытии окна и уходе приложения в фон; отдельного таймера и фонового сборщика нет. WebSocket работает при открытом окне и отключается в фоне/при закрытии; REST восстанавливает снимки после открытия и событий инвалидирования. Токены, вложенные агенты и повторные попытки не выдумываются при отсутствии соответствующих данных.

## Проверка
Сборка актуальных исходников: PASS. Проверяются переходы replay, реальные временные метки, объединение событий и изоляция/ограничения архива. XCUITest открывает настоящее окно роли из живого графа; содержимое таймлайна задаётся DEBUG-фикстурой из трёх действий, включая ошибку. Это подтверждает UI, а не наличие серверной истории для всех исполнителей. На iPhone не установлено.
