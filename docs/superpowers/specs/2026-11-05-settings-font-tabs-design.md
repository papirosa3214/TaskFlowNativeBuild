# Компактные настройки шрифта

Дата: 05.11.2026  
Статус: ожидает утверждения владельца

## Замысел

Убрать раздутый блок «Внешний вид». Настройки шрифта приложения и чата разделить, но открывать из одной понятной строки «Шрифт».

## Компоновка настроек

Отдельный раздел «Внешний вид» удаляется. «Пользовательские настройки» остаются; в них по-прежнему живут тема, иконка, системный таббар, кнопка создания задачи, новая панель ввода и остальные текущие строки. Добавляется одна строка «Шрифт» с шевроном.

Строка открывает экран «Шрифт» с двумя системными вкладками:

- «Приложение»;
- «Чат».

Вкладки независимы: у каждой свой тон, стиль шрифта, размеры и живой образец. Термин «Гарнитура» в интерфейсе заменяется на «Стиль шрифта». Поясняющих абзацев на экране нет.

## Вкладка «Приложение»

1. «Тон» — текущие четыре цвета.
2. «Стиль шрифта» — текущий набор шрифтов с кириллицей.
3. «Размер» — пять строк с дискретными системными `Slider`: заголовок, подзаголовок, основной, второстепенный, мелкий. Справа — фактический кегль, а не «мельче / обычный / крупнее».
4. «Образец» — карточка задачи, где одновременно видны все пять типов. Образец меняется во время движения регулятора.

Общая шкала «Размер текста» удаляется как дублирующая пять отдельных регуляторов. Системный Dynamic Type остаётся.

## Вкладка «Чат»

Компоновка та же, но хранилище и значения отдельны:

1. Свой «Тон».
2. Свой «Стиль шрифта».
3. Шесть фактических групп ленты: основной, жирное выделение, заголовок, код, размышления, мелкий.
4. Образец ответа роли показывает все шесть групп одновременно.

Тон и стиль чата действуют на содержимое ленты. Системная шапка, кнопки и панель ввода остаются частью интерфейса приложения.

## Смежные исправления

- В «Искусственном интеллекте» строка «Голос Помощника владельца» остаётся переходом с шевроном, но техническое имя голоса справа не показывается.
- В «Сервере» остаётся одна внешняя карточка. `SystemControlSection`, `ServerRestartRow` и `ServerStatusSection` перестают рисовать вложенные `TFCard`; внутри остаются строки, разделители и ошибки.

## Рассмотренные варианты

1. Вкладки «Приложение»/«Чат» — выбрано: два больших набора не смешиваются.
2. Два последовательных блока — отклонено: два набора регуляторов и образца снова делают экран длинным.
3. Старая компоновка в «Внешнем виде» — отклонена как слишком громоздкая.

## Не делаем

- Не меняем состав пяти групп приложения и шести групп чата.
- Не меняем веса и начертание `RoleReplyMarkdown.readableText`.
- Не добавляем подсказку: это перекомпоновка уже существующих настроек, а не новая функция.
- Не запускаем симулятор, UI-тесты и установку на iPhone без отдельного поручения.

## Технические решения

- Вкладки — чистый системный segmented `Picker`; регуляторы — чистые дискретные `Slider` без своих tint, background, overlay и рамок.
- Число справа — базовый кегль после выбранного множителя, округлённый до целого. Dynamic Type поверх него в числе не отображается.
- Старый общий размер мигрирует в пять групп только если их ещё не настраивали; уже выбранные значения не затираются.
- Первое значение тона чата копируется из текущего общего тона; стиль чата начинается с системного шрифта, чтобы сохранить текущий вид.
- В чате выбранный стиль действует на пять обычных групп; код остаётся моноширинным.
- В светлой теме сохраняется действующее правило: пользовательский тон влияет только на тёмную тему.
- Для тона чата вводится отдельный цветовой токен. Он подключается к центральным рендерам ленты, включая HTML-ответы; корневого модификатора недостаточно, потому что часть компонентов явно задаёт `Color.tfText`.

## Проверка

Логика независимых настроек приложения и чата получает целевые unit-тесты RED → GREEN без симулятора. Компоновка — точечная сборка под устройство без подписи, `design-system-guard` и diff. Визуальная приёмка остаётся за владельцем.
