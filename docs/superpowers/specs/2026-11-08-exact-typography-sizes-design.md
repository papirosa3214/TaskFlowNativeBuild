# Точные кегли приложения и чата

Дата: 08.11.2026

## Намерение

Сделать иерархию шрифтов заметной и предсказуемой: каждая семантическая
группа получает точный кегль, а списки задач и экранные заголовки читают
те же настройки.

## Выбранный вариант

Для каждой группы — компактное числовое поле с суффиксом `pt`. Можно ввести
любое целое значение от 8 до 72. Больших полос, сегментов и фиксированных
ступеней нет. Некорректное или пустое значение не сохраняется; при завершении
ввода поле возвращает последний допустимый кегль.

Рассматривались два других варианта:

- расширить набор готовых ступеней — отклонено, потому что снова ограничивает выбор;
- добавить шаговые кнопки `−/+` — отклонено, потому что раздувает каждую строку.

## Шкала приложения

- «Заголовок» — экранные заголовки капсом, в том числе `ЗАДАЧИ` и `АРХИВ`.
- «Подзаголовок» — заголовки разделов и карточек.
- «Основной текст» — название задачи и основной текст.
- «Второстепенный текст» — описание задачи.
- «Мелкий текст» — срок, статус, метки и счётчики.

Общий и архивный списки используют один `TFTaskRowContent`, поэтому оба получают эту
иерархию одинаково.

## Шкала чата

Шесть текущих групп чата остаются независимыми: основной, жирное, заголовок,
код, размышления и мелкий. Каждая получает своё числовое поле `8…72 pt`.
Моноширинная гуппа остаётся моноширинной.

## Хранение и миграция

Точные кегли хранятся отдельно для каждой группы приложения и чата. При первом
запуске новой схемы каждая группа получает точный кегль из её текущей выбранной ступени.
Вид текста после обновления не скачет. Старые ключи остаются только для миграции.

Пользовательские кегли продолжают масштабироваться по системному Dynamic Type. Точное число
— базовый кегль при стандартном системном размере.

## Границы

- Не менять веса, цвета и геометрию строк задач.
- Не превращать названия самих задач в капс: капс относится только к группе
  экранных заголовков.
- Не менять гарнитуры, тон и содержание образцов, кроме отображения точных кеглей.
- Без симулятора, UI-тестов и установки на iPhone без отдельного поручения.
