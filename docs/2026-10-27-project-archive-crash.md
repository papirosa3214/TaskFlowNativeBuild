# Вылет при архивации проекта — диагностика 27.10.2026

## Симптом

Владелец: приложение вылетает сразу при нажатии «В архив» проекта. Уточнено владельцем: нажатие в свайпе, окно подтверждения не появляется. Значит, обработчик подтверждения и запрос DELETE ещё не выполняются.

## Проверенные факты

- `ProjectsScreen.requestDelete` только устанавливает `DirectoryConfirmRequest`; запрос архивации отправляется после подтверждения.
- `DirectoryConfirmModifier` представляет собственную шторку на `TFBottomSheetContent`, при подтверждении одновременно очищает request и вызывает обработчик.
- `ProjectStore.delete` сначала удаляет проект из массива, затем отправляет DELETE; ошибка возвращает снимок списка и записывает errorMessage.
- Список проектов использует `ForEach(visibleProjects)` со стабильными идентификаторами, не индексы массива.
- Физический iPhone подключён; список systemCrashLogs прочитан через devicectl. Последний доступный обычный crash TaskFlow — 25.10.2026 23:34:44; свежего отчёта за 27.10 нет.
- Три прочитанных отчёта 25.10 (20:19:58, 20:30:43, 23:34:44) показывают SIGKILL / FRONTBOARD / watchdog, стеки UIKit/SwiftUI. Они не доказывают связь с текущим действием.
- Отчёт cpu_resource 26.10 23:16:42 также не устанавливает связь с архивацией.
- idevicecrashreport не видит телефон; devicectl читает его успешно. Отчёты на телефоне не удалялись.

## Ограничения и продолжение

Причина текущего вылета не установлена. Нужны точная точка нажатия и свежий отчёт/консоль для соответствующего события. Не применять предположительные изменения общих шторок или списка без доказательств. Исходники не изменялись; тесты, сборка, установка и UI-автоматизация не запускались. Сырые отчёты сохранены только в /tmp, в репозиторий не добавлены.

## Уточнение локализации

Вылет ограничен цепочкой DirectorySwipeRow → requestDelete → directoryConfirm → TFBottomSheetContent. Одновременное закрытие подтверждения и изменение списка не объясняет этот симптом: до подтверждения владелец не доходит. Запущено подключение консоли установленного приложения через devicectl; ожидается ручное повторение владельцем.
