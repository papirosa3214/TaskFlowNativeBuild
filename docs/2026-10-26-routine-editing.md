# Задание и редактирование рутин — 26.10.2026

## Поведение

Нажатие в «Моих рутинах» открывает существующую рутину в редакторе: полное задание агенту, исполнитель, проект, приоритет, длительность и расписание. Задание поднято перед настройками расписания. «Сохранить изменения» обновляет ту же рутину через PATCH; новая рутина создаётся через POST. «История запусков» — отдельная ссылка внизу редактора; созданная задача по-прежнему открывается из истории.

Правка действует на будущие запуски, не меняет созданные задачи и сама не снимает паузу. Существующий шаблон копируется перед изменением полей формы: метки и флаги исследования/проверки сохраняются (сервер также уже сохранял отсутствующие ключи через merge). Снятие исполнителя, проекта, длительности и задания передаёт явный JSON null: иначе merge сохранял старое значение. Подсказка редактора содержит два шага: задание → история; в форме создания этот сценарий не активируется.

## Проверки

Tools/test_routine_editing.py выполняет реальный RoutineFormViewModel, Schedule, форматирование и HintCenter на Mac с подменённым сетевым транспортом. RED: отсутствовали подсказка и перенос скрытых полей; отдельный RED показал отсутствие null при снятии настроек. GREEN: 2 XCTest + 12 поведенческих проверок (загрузка задания/расписания, PATCH исходного ID, сохранение полей, явная очистка, POST создания, ошибка сохранения, ход подсказки).

Swift frontend parse PASS, design-system guard PASS, diff --check PASS. xcodegen generate выполнен. Симулятор и UI-тесты не используются; внешний вид оценивает владелец.
