## По каждой паре

- **Обзор — без изменений.** Разница только в часах статус-бара и единичных пикселях
  внизу кадра (строка 2480 и 2660). Разметка, отступы, кегли, цвета, шевроны, иконки
  и фон совпадают.
- **Настройки — без изменений.** Разница только в часах статус-бара (строки 80–139).
- **Роли/Агенты — без изменений.** Разница только в часах статус-бара (строки 80–139).
- **Интеграции — изменение: положение шеврона в строке вебхуков; устранено обрезание
  статуса; в подписи «Composio» точка обрезания сдвинулась на один символ.** Причина
  одна — переход на канон `TFListRow` (VAL-UI-007): ручной шеврон
  `Image(systemName: "chevron.right")` рядом со статусом заменён на канонический
  `chevron: .shown`, из-за чего:
  - текст статуса вебхуков перестал обрезаться: «статус недоступ…» → «статус недоступен»;
  - в подписи Composio («Основные интеграции и каталог серв…» → «…каталог серви…»)
    обрезание сместилось на один символ — та же строка, тот же канон, ширина подписи
    считается теперь самим `TFListRow`.
  Изменение разрешено контрактом: вид меняется там, где стоял отброшенный вариант, —
  ручная строка с шевроном была именно таким местом. Остальные строки экрана
  (Linear, Gmail, Apple Календарь, Apple Напоминания, Things 3, Google Задачи,
  Google Календарь) и все разделы не изменились.

Снимки эталонов (SnapshotTests) не перезаписывались.
