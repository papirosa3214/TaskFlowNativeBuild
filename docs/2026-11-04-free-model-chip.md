# Чип «Бесплатно» в выборе модели

В шторке выбора модели чата рядом с названием бесплатного варианта появился чип «Бесплатно». Используется существующий TFPill; звезда и столбики стоимости сохранены. VoiceOver сообщает бесплатность.

Признак — явный вариант провайдера: OpenCode Zen с окончанием `-free`, OpenRouter с окончанием `:free`. Платная версия той же модели, подписка и локальная Ollama автоматически бесплатными не объявляются. Признак вычисляется для новых моделей из обновляемого серверного каталога, без списка конкретных названий.

Проверки: host XCTest 10/10; до добавления реализации новый тест не компилировался из-за отсутствия isFree. Swift parse, design-system-guard и git diff --check прошли. Симулятор, UI-тесты, сборка и установка на iPhone не выполнялись. Внешний вид ожидает оценки владельца.

Серверный инцидент и обновление каталогов — отдельная серверная правка codex/model-catalog-refresh.
