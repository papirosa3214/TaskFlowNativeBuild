# Доставка через PR без CI — 04.11.2026

Порядок владельца: ветка → исключительно точечные локальные проверки изменённой логики и файлов → публикация → настоящий PR → агент сам вручную сливает PR. PR остаётся местом просмотра diff и фиксации слияния; владелец не нажимает Merge и не даёт повторное разрешение. CI и автослияние отключены.

Полные и глобальные тестовые прогоны запрещены. Нет автоматического общего typecheck или сборки вместо точечной проверки. Для документации — diff и поиск противоречий, без тестов. Штатная сборка сервера при выкладке отдельно от тестов. Серверные точечные тесты — только явные файлы с maxWorkers=4. Запрет самовольного симулятора/UI-тестов/установки сохранён.

Обновляются AGENTS.md, CLAUDE.md и AGENT-CYCLE.md iOS; глобальные инструкции Codex/Claude на маке и Claude на .110; серверный INDEX.md (также AGENTS.md/CLAUDE.md через симлинки), PROJECT-START, общий канон SYSTEM.md ролей и инструкция интеграции в agentState.ts. Канон разворачивается в существующие homes ролей. Старый рецепт KB заменяется по тому же имени, чтобы поиск больше не выдавал обязательный CI.

Проверка этой работы — только diff и поиск противоречий в изменённых инструкциях. Тесты и симулятор не запускались. Внутренняя очередь TaskFlow и её восстановление — отдельный механизм от GitHub CI; инструкции не должны отправлять новые правки ждать отключённый CI.
