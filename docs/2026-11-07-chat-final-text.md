# Завершённый ответ в чате без истории действий

## Решение владельца

После ответа роли в чате остаётся только результат: текст, файлы, таблицы,
виджеты и прочие блоки сообщения. История действий и размышлений больше не
показывается. В карточке задачи и окне работы роли она сохраняется.

## Причина дубля на скриншоте 07:52

В БД одна запись ba60d463-9ac3-44a5-be12-f2aaffb6320a. В steps находится
развёрнутый текст хода, в text/envelope — переформулированный итог. Чат
выводил обе версии. Буквальное сравнение текстов не могло убрать повтор.

## Изменения

- Из обоих вариантов завершённой строки чата удалён вывод work items.
- Единственный ответ — сохранённое сервером сообщение с его блоками.
  Не выбираем ответ из последней реплики steps: сервер может удалить оттуда
  финальный текст, оставив только «сейчас проверю». Этот риск выявил ревьюер;
  экспериментальный helper был удалён до публикации. Формулировка итога может
  отличаться от промежуточного потока, но дублирующего текста рядом нет.
- Готовое сообщение сразу занимает место живого хода; больше не скрывается
  в ожидании playback callback. Повторная доставка завершения идемпотентна.
- REST snapshot фильтрует завершённые ходы и ходы с уже сохранённым ответом.
- Не изменены RoleChat.swift, общие RoleLiveTurnBubble/RoleLiveItemsList,
  TaskLiveActivityView, серверные steps и API. Карточка задачи продолжает
  получать полную историю. Связь сообщения с задачей ничего не удаляет.

Общая функция слияния действий остаётся прежней: замечание ревьюера об
обновлении статусов в ней не исправлялось. Для завершённого чата её кэш
устранён, а изменение общего компонента затронуло бы отдельное окно задачи.

## Проверки

Host Swift выполняет настоящий completeLiveTurn: RED до исправления,
GREEN после; end до/после сообщения, повторное завершение, alreadyShown.
Исполняется реальный фильтр REST snapshot для ended/answered/new.
Проверки отсутствия истории в обоих chat renderers и сохранности отдельного
task renderer; terminal-turn regression; Swift parse; design guard; diff.
Проверки не являются визуальной приёмкой на iPhone.
