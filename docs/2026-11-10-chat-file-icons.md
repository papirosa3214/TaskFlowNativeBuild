## Что сделано

1. `ChatLinkPresentation` — таблицы T3 Code (`apps/mobile/src/lib/markdownLinks.ts`,
   MIT) перенесены один в один: иконка по расширению (90+ расширений),
   иконка по полному имени (`package.json` → npm, `Dockerfile` → docker,
   `readme.md` → markdown, `tsconfig.json` → typescript, `.gitignore` → git),
   цвет подписи по языку (`tint(forIcon:)`).
2. `Resources/Assets.xcassets/file-*.imageset` — 56 иконок набора pierre из
   того же репозитория (MIT), режим `original`: иконки цветные, как в макете.
3. `RoleReplyMarkdown`: подпись файла получает цвет языка
   (`ChatBadgePalette`), перед подписью — иконка. Начертание остального текста
   ответа не менялось.
4. `MarkdownDocumentRenderer`: то же для заметок и документов.
5. Правило «что считать файлом» осталось: без каталога файлом считается имя с
   известным расширением или известное имя (`Dockerfile`), иначе любое слово с
   точкой стало бы «файлом».

## Ограничения

- Иконки — картинки в тексте (`Text(Image(...))`): размер идёт от кегля
  строки, выравнивание — по базовой линии. Как именно они встают в живом
  абзаце, проверяется глазами владельца: симулятор и телефон не запускались.
- Набор иконок фиксированный (56 картинок в бандле): новый язык появится
  только с новой картинкой — в T3 ровно так же.
- Строки «Источники» из макета `envelope-badges-preview.html` по-прежнему не
  делались: это отдельный блок ответа, его должен готовить сервер.
