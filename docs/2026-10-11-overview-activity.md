# Активность и недельная сводка в iOS

На «Обзоре» добавлена плоская календарная карта за 12 недель: столбец — неделя, строки — понедельник–воскресенье. Считаются выполненные задачи с completed_at, включая архив, без повторного счёта одного ID. Даты сгруппированы по местному календарному дню. Задачи без даты завершения не приписываются произвольному дню. Нажатие клетки показывает дату и количество; будущие дни выключены. Используется существующий tfGreen, шрифты и TFCard приложения. 3D и веб-компонент не встроены.

Кнопка Second Brain раньше содержала пустое действие. Теперь открывает системную шторку SwiftUI с недельной сводкой через те же GET /api/ai/weekly-summary и POST /api/ai/weekly-summary/refresh, что использует веб. Системные List, Section, LabeledContent, toolbar и кнопка «Готово»; веб-оформление не переносилось. Ошибка загрузки показывает повтор, готовая сводка сохраняется при обновлении.

Проверка: локальный день с переходом UTC-полуночи, семь строк календаря, декодирование контракта сервера, XCUITest карты, открытия/закрытия шторки и ответа живого сервера (ошибка 503). Результат и кадры сохраняются рядом. Физическая установка подтверждается отдельно.

Дополнение: четыре блока состояния перенесены без изменения счётчиков и маршрутов из «Обзора» в начало «Проектов», выше «Без проекта» и архива. Обе шапки используют системный inline с первого кадра.

Живая генерация сводки сейчас заблокирована сервером: локальная модель возвращает HTTP 503, maximum pending requests exceeded. Проверен запрос и отображение ошибки с повтором; успешный текст сводки на живом сервере пока не подтверждён. Сервер/модель не перезапускались.

Итог проверки: 3 теста прошли; кадры карты, проектов и шторки с серверной ошибкой сохранены.
