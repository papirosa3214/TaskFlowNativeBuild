# Чат карточки: закрытие только за верхнюю ручку

Статус: правка внесена, финальная проверка ручки НЕ завершена; не закоммичено и не отправлено.

Владелец подтвердил: свайпы переписки только листают сообщения, закрытие — сверху за ручку.

TaskFormScreen открывает TaskChatSheet. У этого вложенного окна системное интерактивное закрытие отключено; ручка с отдельным DragGesture закрывает через dismiss при движении вниз >45 pt. Ручка также доступна кнопкой для accessibility. Общая шторка карточки не менялась.

Проверки: первая сборка тестов остановилась на чужой ошибке Tests/ServiceTicketPresentationTests.swift:199 (мутация let check). Для изоляции только в генерируемой xcscheme исключены unit/snapshot targets; исходники этих тестов не менялись. Первый выполненный UI-прогон достиг чата с 46 сообщениями, но до начала истории не дошёл; тест упал на отсутствии новой ручки (не доказательство воспроизведения нежелательного закрытия). Второй выполненный прогон открыл чат с одним сообщением: четыре свайпа вниз по chat.feed не закрыли окно, кадр after-feed-swipes.png. Ручка есть, но handle.swipeDown() не закрыл окно. Область ручки 32 pt, порог 45 pt; гипотеза — короткий синтезированный жест. Тест подготовлен к элементному перетягиванию на 160 pt; повтор не выполнен из-за лимита двух UI-прогонов AGENT-CYCLE.md. Требуется разрешение владельца на один дополнительный прогон. Не объявлять закрытие ручкой работающим до PASS.

Сборка приложения прошла в составе последнего UI-прогона; SourceKit-LSP нашёл TaskChatSheet. Сторож дизайн-системы по двум затронутым файлам: чисто. iPhone исключён владельцем в этой сессии. Метрики производительности не заявляются.
