## Как устроено

Рутина — отдельное расписание с шаблоном: каждый запуск создаёт новую карточку и поднимает роль обычным конвейером. Старый «Повтор» задачи остаётся отдельным механизмом.

Правила: ежедневно, по будням, еженедельно с выбором дня, конкретные дни недели, ежемесячно с выбором числа, интервал от 5 минут. Произвольный cron не включён. Время рассчитывается в зоне рутины, по умолчанию Europe/Moscow.

Планировщик обычно проверяет расписания раз в 5 минут: запуск не обещан секунда в секунду. По умолчанию при незакрытой предыдущей карточке очередной автоматический запуск пропускается. После простоя догоняется один пропуск в пределах 24 часов. Пауза и удаление рутины не удаляют уже созданные задачи. Ручной запуск — отдельная проверка; он не доказывает автоматический запуск по времени.

## Порядок проверки владельцем после доставки клиента

1. «Обзор» → «Мои рутины» → «+».
2. Назвать «Проверка рутин», выбрать «Ежедневно», время на 10–15 минут вперёд и Europe/Moscow. Указать проект и роль. Задание роли сделать коротким, без внешних действий: написать проверочный ответ в карточке.
3. Оставить включёнными пропуск при незакрытой прошлой карточке и догон. Проверить ближайший запуск в превью, сохранить.
4. Дождаться времени плюс один интервал планировщика. Открыть рутину: в истории должен быть запуск и переход в одну новую карточку. В карточке — выбранная роль и её результат. Повторное обновление не должно давать дубль.
5. Свайп вправо по строке открывает паузу/возобновление и «Запустить сейчас»; тап по строке — историю; свайп влево — удаление с подтверждением (по сохранённому Swift-коду ветки).
6. Для проверки наложения использовать интервал, оставить предыдущую карточку незакрытой и дождаться очередного автоматического запуска: история должна показать пропуск с причиной. Пауза должна остановить будущие автоматические запуски.
7. После проверки удалить тестовую рутину; созданные карточки остаются и убираются отдельно.

Если строки «Мои рутины» нет, это не ошибка пользователя: нужный клиент ещё необходимо интегрировать и установить.

## Уточнение владельца: автоматизации в планировании

Подтверждено владельцем в этом чате 23.10.2026:

- Автоматизации выполняют агенты: дайджесты, уроки английского, сбор информации и другие материалы.
- Будущие запуски заранее видны в «Сегодня», недельном и месячном планировании как расписание. Это позволяет видеть уже настроенную нагрузку и выбирать время новых автоматизаций.
- Карточки заранее не создаются. Будущие отметки рассчитываются по правилу расписания только для отображения; реальное выполнение создаётся при срабатывании.
- Автоматизация визуально отличается от обычной задачи небольшой отметкой; нужны повторяющиеся и разовые варианты.
- В «Итоге» каждого исполнения находится полный полезный материал: сам дайджест, урок и т. п. Лента активности сохраняется, но не заменяет результат.
- Материал можно открыть, поделиться им и скачать.

Будущая отметка определяется парой «автоматизация + назначенное время». До запуска открывает настройки автоматизации. После появления реального исполнения эта же позиция показывает его состояние и результат, без второй строки в календаре. Изменение расписания пересчитывает будущие отметки, история выполненного сохраняется. Расписание показывает ожидаемые запуски; это не гарантия выполнения при паузе, сбое или политике пропуска.
