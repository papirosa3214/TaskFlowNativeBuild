# Строка сессии внутри роли без аватарки, общий список чатов — с аватаркой

Дата: 11.11.2026. Проект: TaskFlow Native iOS. Ветка: `roles/3e8b9b3b-541a-40a3-93f0-9544a10cf7ea`.
Реестр: `LOCK-CHAT-SESSION-AVATARS-20261111`.

## Что было

Строка списка чатов одна на все виды (`ChatListRow`), кружок собеседника ей
отдавался полем `member`. Внутри экрана конкретной роли (`RoleChatsScreen`,
выбрана роль на панели) каждая строка сессии получала кружок той же самой роли —
он ничего не различал, роль уже названа заголовком экрана.

## Что сделано

- Правило видимости вынесено в чистую модель, а не в разметку строки:
  `RoleSessionList.showsAvatar(in:)` — `.role` → `false`, `.groups` → `true`
  (`Sources/Core/Models/RoleSessionList.swift`).
- `rowMember(_:)` в `Sources/Features/Roles/RoleChatsScreen.swift` отдаёт
  участника строке только там, где аватар нужен: общий список чатов (`isHome`)
  и каталог групповых чатов. Внутри роли возвращает `nil`, поэтому строка
  рисуется только текстом, левый отступ остаётся обычным.
- Разделители строк под кружок (`rowDivider(afterAvatar:)`) считаются от той же
  `rowMember`, поэтому внутри роли отбивка стала ровной по тексту.

списка сессий; история чата и его шапка не менялись.
