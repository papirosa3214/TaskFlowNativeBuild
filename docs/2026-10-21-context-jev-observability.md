# Наблюдаемость контекста и JEV — 21.10.2026

Согласовано владельцем: «Обзор → Загрузка ролей» показывает вклад энричеров и JEV; «Настройки → Оценщик JEV» показывает расход по сохранённому ключу. Старт разрешён 21.10.2026.

## Реализация
1. Сервер: журнал операций с task/step/role/run, стартом, завершением, временем, причиной пропуска/ошибки, входным/выходным количеством и списком источников. AsyncLocalStorage изолирует параллельные роли. Учёт токенов по непрозрачному отпечатку провайдера и ключа; сам ключ не выдаётся. Неизвестный usage не равен нулю. Никаких платных проб для статистики.
2. Python TaskContext: отдельные результаты KB/Mnemosyne/repository/dependencies/history, время поиска и фактически включённые в ограниченный prompt данные; мост сохраняет метаданные. Сбой журнала не ломает рабочий запуск.
3. JEV: все пять сценариев, вызовы, причины fallback, конкретный результат отбора/оценки; тест подключения тоже учитывается. API статистики только владельцу. Периоды 24 часа, 7 и 30 дней; в загрузке также 3 дня. Без подтверждённого тарифа/баланса показывается недоступность денежных данных, не выдуманный ноль. Локальный учёт обозначен как расход TaskFlow с датой старта.
4. iOS: секция под текущим графиком, сводка и последние операции с деталями и переходом к карточке. В настройках — расход текущего ключа по периодам/сценариям. Ошибки загрузки отдельны от пустой истории. Подсказки новой функции.
5. Сторож журнала: транзакционная проба записи/чтения/агрегации с rollback, уведомление в состоянии системы с ограничением частоты. Запись в docs/watchers.md.

## Проверка
До логики — падающие тесты. Сервер: mock-провайдер, независимые параллельные контексты, смена ключа, неизвестный usage, ошибка и timeout, отсутствие секретов в публичном ответе, права owner, периоды, сторож. Python: обрезка и источники. iOS: декодирование и состояния, целевой XCUITest в симуляторе и на iPhone. Не создавать живые задачи. Перед выкладкой проверить пустую очередь: активные роли не прерывать. Коммиты только своих файлов, без push.
