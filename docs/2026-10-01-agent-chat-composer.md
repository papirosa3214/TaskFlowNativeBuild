# Панель ввода в чатах с агентами — 01.10.2026

## Поведение
- «Остановить» — плоская иконка справа внутри основной пилюли. Во время ответа можно готовить следующий текст; остановка не стирает черновик. Отдельная кнопка в ленте удалена.
- В той же пилюле — системное меню режима: Работа, Планирование; у Исследователя — Глубокое исследование. Выбор сохраняется для чата. Отправленное сообщение и повтор отправки сохраняют выбранный режим, включая голосовые сообщения.
- Текст идёт по словам с ограниченной скоростью догоняющей очереди (до 320 символов/с), проявляется прозрачностью за 0.25 с без размытия. Готовый ответ не обгоняет непоказанный хвост. Reduce Motion отключает проявление букв.

## Серверный контракт
POST /api/chats/:id/messages принимает work_mode: work | plan | deep_research. Без поля — прежний work. Режим хранится у сообщения (миграция 083_chat_work_mode) и переносится через очередь и передачу слова.
Планирование: allowlist инструментов чтения на уровне MCP, CLI и tool_call. bash/edit/write, изменения трекера и неизвестные инструменты заблокированы. Если ограничения невозможно применить, ход не запускается.
Глубокое исследование адресуется Исследователю: исследовательские вопросы, сопоставление первичных источников, противоречия/даты, выводы и ссылки. Для модели с reasoning включается high; модель роли не подменяется.

## Найденные особенности SwiftUI
.task без id удерживал старое isComplete=false: callback завершения не срабатывал. .task(id: isComplete) перезапускает цикл, сохраняя очередь в State.
accessibilityIdentifier на контейнере пилюли перекрывал идентификаторы дочерних кнопок; идентификаторы оставлены на управляющих элементах.
