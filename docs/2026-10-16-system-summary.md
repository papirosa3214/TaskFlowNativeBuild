# Развёрнутая общая сводка — 16.10.2026

## Поручение
При переходе в «Состояние системы» сразу видеть общую развёрнутую сводку
по образцу «Сводки работы сервера», вместе со счётчиками уведомлений и поломок.

## Изменение
В общей карточке сверху остаются кликабельные счётчики, ниже сразу
раскрыто существующее содержимое NotificationTicketDetailSheet: ошибки,
успешные проверки, время и связанные карточки диагностики. Используется
тот же компонент без вложенного ScrollView. Загрузка и pull-to-refresh
обновляют одновременно состояние и сводку. Дублирующая плашка общей
сводки исключена из «Все уведомления». Добавлена подсказка.

## Проверка
Скан оформления прошёл. Сборка устройства запущена. Автоматический UI-обход
не выполняется: владелец ранее взял визуальную приёмку на себя.
Окончательный результат сборки и установки будет дописан по факту.

## Ограничения
Счётчики событий за день и карточек ремонта имеют прежний смысл.
Ошибка загрузки сводки не прячет счётчики поломок. Живые данные серверных
проверок остаются снимками с отметкой времени, не непрерывной телеметрией.
