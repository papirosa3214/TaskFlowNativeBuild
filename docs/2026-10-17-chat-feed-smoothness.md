# Устойчивость ленты чата — 17.10.2026

## Диагноз

- Автопрокрутка при изменении истории следила только за `messages.last`, причём прокручивала лишь если последнее сообщение было от владельца. Новый ответ помощника мог остаться ниже видимой области.
- Живой ответ и его сохранённая версия получали разные `ForEach`-идентификаторы (`playbackID` и `message.id`). При замене строки переменной высоты SwiftUI мог пересоздать её и потерять scroll anchor.
- Переход из «Содержания» передавал ID сообщения напрямую в `scrollTo`, хотя идентификатор строки ленты мог отличаться.

## Изменения в исходниках

- Следим за последней строкой ленты и после вставки прокручиваем к нижнему якорю, если пользователь не ушёл читать историю.
- Даём live-ответу и сохранённому сообщению один ID по автору и исходному сообщению-запросу.
- Перед переходом из «Содержания» разрешаем ID сообщения в актуальный ID строки.
