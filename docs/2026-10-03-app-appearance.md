# Светлая и тёмная тема TaskFlow

03.10.2026. Канонический проект `/Users/max/Проекты/TaskFlowNativeBuild`.

## Итоговое поведение

Настройки → Пользовательские настройки → Тема: прежний TFToggle в прежней строке. Включён — тёмная тема, выключен — светлая. Внешний вид тумблера не менялся. Меню с тремя вариантами убрано по указанию владельца.

Binding переключателя пишет в общее AppStorage `taskflow_appearance`, которое читает корневая сцена. Тема применяется сразу и сохраняется между запусками. Существующий boolean `taskflow_settings_dark_theme` мигрируется один раз, новый выбор имеет приоритет. Без сохранённого выбора остаётся тёмная тема. Ранее сохранённый system корректно отображается в тумблере по текущему colorScheme; первое переключение выбирает явную светлую/тёмную тему.

Снята принудительная тёмная тема в project.yml и TaskFlowApp. Использованы существующие светлые поверхности, светлые подписи/статусы затемнены для контраста. Тёмные токены не изменены. Компоновка, остальные кнопки и серверные данные сохранены.
