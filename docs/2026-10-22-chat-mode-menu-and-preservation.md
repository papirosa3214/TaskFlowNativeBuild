Новые изменения после времени снимка не покрыты архивом.

Для проверки контейнера: `git bundle verify <путь.bundle>`. Для изучения содержимого: `git bundle list-heads <путь.bundle>`. Любое восстановление делается выбранным пакетом с его базой, сравнением с текущим main и проверкой конфликтов. Патчи старых деревьев не накладывать целиком на основной main. Никаких автоматических слияний, reset, checkout, stash или push не выполнялось.

Первыми к точечному переносу готовы для рассмотрения четыре коммита eager-wolf; остальные группы требуют проверки на уже существующее поведение. В рамках текущего поручения подготовлено сохранение, без включения этих исторических изменений в основное приложение.
