# Живой поток исполнителя в графе
Дата: 08.10.2026.

## Результат
Окно роли использует тот же RoleLiveTurnBubble, что чаты: растущий текст, вызовы инструментов с состоянием выполнения. Событие tasks:live и GET /tasks/:id/live несут task_id, subtask_id и run_id. Исполнители одной роли в параллельных слотах не смешиваются. После завершения последний снимок сохраняется сервером до 30 минут.

Граф ранее передавал только source_subtask_id, отсутствующий у локального узла плана. Теперь используется также id связанной подзадачи. Для исполнителей без нового канала остаётся изолированная лента действий с текстом и временем.

## Проверки
- Сервер: build и 22 теста (19 существующих чатов, 3 новых потока).
- iOS: build, 4 теста декодирования и изоляции.
- XCUITest на реальной карточке архитектора: окно графа показало действия текущего шага, 1 PASS.
- Реальный токеновый поток нового серверного канала на iPhone ещё не проверен.

## Подключение
Серверная часть подготовлена в отдельном worktree. Для активации нужен деплой dist и безопасный перезапуск. Нельзя прерывать текущие заходы ролей без согласования. Существующий до обновления заход не получит задним числом текстовые события. Нативное приложение на iPhone ещё не установлено.

## Границы
Поток подключён к inProcessRun. Внешние исполнители, которые присылают только activity, показывают ленту действий. Отчёты и постоянная история не заменяются временным снимком. При рестарте сервера снимки исчезают.
