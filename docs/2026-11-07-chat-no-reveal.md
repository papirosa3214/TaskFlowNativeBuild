# Вывод блоков без искусственной задержки

По поручению владельца 07.11.2026 снят roleMessageReveal с готовых ответов
чата. Раньше отключение live pacer оставляло отдельное проявление готового
сообщения активным, поэтому предыдущая правка не убрала эффект полностью.

RoleLiveTurnBubble по умолчанию выводит полученные items напрямую без
очереди печати и fade, в том числе в окне задачи. RoleThinkingWindow
показывает полученный текст напрямую, без pacer, таймеров и fade.
Данные шагов задачи, серверная передача блоков и разбор виджетов не менялись.
Готовые блоки показываются при получении; клиент не добавляет ожидание.

Проверки: diff, Swift parse двух файлов, design guard, host completion и
snapshot regressions. Отдельный UI-тест не создавался и не запускался.
