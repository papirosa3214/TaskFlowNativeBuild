# Нативное окно сессии — 07.11.2026

## Результат
Кнопка с ползунками открывает системный popover, в том числе на iPhone. Собственные фоновые карточки и заголовки разделов удалены. Строки разделены системными Divider: текущая модель, текущая папка, контекст, Фото/Файл/Камера и переключатель Работа/Планирование/Цель. Исследование скрыто; ранее сохранённое значение этого режима для личной сессии переводится в Работу.

Модель открывает существующий выбор модели, папка — существующий браузер рабочего пространства. Контекст каждый раз начинается со средней высоты и допускает разворот до полной. Выбор вложения сначала закрывает popover, затем по завершении закрытия открывает нужный системный инструмент; повторное событие закрытия не открывает его заново.

## Режимы
Владелец подтвердил все три режима. Серверная реализация не менялась: Планирование ограничено инструментами чтения, Работа использует доступные роли инструменты, Цель включает существующий цикл продолжения до завершения, остановки или лимита. Цель не гарантирует достижение результата.
