# Подключение текстовых блоков чата к настройкам — 07.11.2026

## Проблема
Работа c5886f2c добавила отдельные гарнитуры для групп и обновление образцов, но не устранила ограничение, записанное в LOCK-SETTINGS-FONT-TABS-20261105. В корнях чата tfChatTypography отключает шкалу приложения; общий tfText при этом выбирал фиксированный системный шрифт. Структурированные ответы, таблицы и виджеты с tfText обходили шкалу чата. В коде и ряде карточек были прямые системные font.

## Изменения
- Общий tfText внутри чата читает группу чата: заголовки → heading, основной текст/строки/ввод → body, подписи/метаданные → meta. Вне чата ветвь приложения сохранена.
- Корень чата задаёт наследуемый основной шрифт и отслеживает revision без смены identity/сброса навигации.
- Прямые системные шрифты заменены на наблюдающий revision tfChatText у таблицы, кода/команд, карточки вопросов, текстовых частей виджетов и заголовка HTML-артефакта. Крупные цифры сохраняют исходные пропорции, но масштабируются выбранной группой.
- Код общего рендерера документов в чате читает mono, вне чата оставлен прежним. RichRun в таблицах и структурированных документах получает свою группу: обычный → body, жирный → emphasis, код → mono; жирный заголовок остаётся heading. Таблицы наблюдают revision для обновления уже открытого текста.
- Уже подключённые Markdown, жирное, заголовки, размышления продолжают читать свои группы. Настройки модели/папки/контекста остаются в шкале приложения, их согласованные системные заголовки не менялись. Размеры SF Symbols не привязаны к кеглю текста.
- Самостоятельное содержимое HTML-артефакта, задаваемое авторским HTML/CSS, сохраняет собственное оформление; это исполняемая страница, а не нативный текстовый блок. Отладочная галерея виджетов не менялась.

## Проверки
Целевой host RED: отсутствовала маршрутизация общих текстовых стилей и rich runs в группы чата. GREEN: все 12 стилей распределены по heading/body/meta; пять сценариев rich runs проверяют жирное, код, приоритет кода, заголовок и обычный текст. Существующие проверки независимости приложения/чата, наследования/сброса гарнитур и моноширинного кода PASS. Swift parse изменённых файлов, diff и design-system guard PASS. UI-тесты и симулятор не запускались. Проверка на телефоне сменой размеров и гарнитур остаётся визуальной приёмкой владельца.
