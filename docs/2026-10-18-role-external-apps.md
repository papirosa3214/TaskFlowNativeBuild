# Внешние приложения Помощника владельца

Открой Настройки → Команда → Помощник владельца → Внешние приложения.

Gmail показывает подключённые адреса и их статус авторизации. «Показать возможности» раскрывает актуальные описания инструментов Помощника владельца из серверного каталога. Подключить адрес или изменить доверенных отправителей можно в Настройках → Интеграции → Gmail.

Things 3 показывает доступ через TaskFlow Host на Mac. «Доступен» появляется только после успешного чтения списка проектов. Эта проверка не создаёт и не меняет дела. Если Mac подключён, но чтение заблокировано macOS, отображается «Нет доступа». Само присутствие Mac в сети не подтверждает доступ к Things. Возможности берутся из определения инструмента роли, поэтому здесь перечислено то, что объявлено текущим сервером.

Оба экрана используют один общий снимок подключений. Gmail обновляется после изменения адресов; оба подключения перечитываются при открытии соответствующего экрана, возвращении приложения на передний план и по кнопке «Обновить доступность».

Раздел Things в «Интеграциях» теперь показывает доступ Помощника владельца через TaskFlow Host. Он заменяет прежнюю карточку ручной синхронизации через отдельный мост.

## Реализация и проверка

Общие данные: `ExternalAppAccessStore`; адреса — существующий `/integrations/composio/gmail/accounts`, каталог — `operations_detail` из `/roles/secretary` (описания из того же `taskflowTools`, что использует общий инструмент), Things — чтение `things_projects` через `/machines/:id/ops`.

Регрессия различает успешный пустой список и ошибку MCP внутри успешного ответа хоста. До реализации проверка дала 1 FAIL из 6 случаев, после — 6 PASS. Это проверка разбора ответа, а не доказательство доступности живого Things.

Проверки приложения и визуальная приёмка записываются ниже после выполнения.

Серверный контракт: `tools` по-прежнему содержит единственную общую точку `taskflow`; новое `operations_detail` описывает вложенные операции из её существующих определений. Отдельного реестра для Gmail/Things не создаётся. Серверный HTTP-тест отсутствия этого поля воспроизвёл ошибку до правки (FAIL), после добавления поля прошёл (PASS); `npm run build` — PASS.

iOS Simulator: сборка PASS. `ExternalAppAccessTests` — 3/3 PASS; новый сценарий `HintCenterTests` — PASS. Первый UI-прогон дошёл до профиля, нашёл Gmail и Things, но остановился при поиске кнопки по идентификатору контейнера. Локатор исправлен на доступный текст; итоговая проверка выполняется на физическом устройстве. Первый кадр сохранён из записи XCUITest.
