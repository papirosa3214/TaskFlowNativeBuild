# Действия конкретного исполнителя

## Изменение
Сервер сохраняет автора и subtask_id каждого действия. Runtime передаёт идентификатор своего шага, поэтому два параллельных builder не смешиваются. Ответ активности дополнен by_subtask: отдельный счётчик, последние действия и текст для каждого шага. Общая лента остаётся общей; iOS под исполнителем использует только его шаг.

Счётчики не теряют точность при переполнении кольца последних 500 действий. Для старых внешних клиентов слот определяется только если у автора ровно один выполняемый шаг; неоднозначные записи не приписываются случайному исполнителю. Проверяется принадлежность шага задаче и автору.

## Проверено
18 серверных тестов: изоляция параллельных слотов одной роли, неизвестный слот, переполнение кольца, существующая лента и аренда. TypeScript build успешен. 2 iOS-теста: отдельные значения и безопасное поведение со старым сервером; финальная сборка успешна.

## Применение
Серверная правка подготовлена и собрана, но пока не загружена в работающий процесс: нужен перезапуск, который прервёт текущие роли. Запрошено решение владельца о моменте применения. iPhone не обновлён — установка обычным install-iphone.sh после применения сервера.

Старые 233 действия не имеют идентификаторов шага и не могут быть точно разделены задним числом. Новые отдельные счётчики начинаются с новых записей после обновления.
