# Карточка задачи: убрано всплывающее окно «Диагностика»

Дата: 24.10.2026. Автор: Разработчик (builder). Реестр: `LOCK-DIAG-WINDOW-REMOVE-20261024`.

## Задача

Владелец 24.10.2026: при открытии карточки задачи всплывает окно «Диагностика»
со счётчиками комментариев, событий и подшагов. Оно неактуально — удалить
полностью, а не изолировать, чтобы не утяжелять код.

## Что сделано

Из `Sources/Features/Task/TaskFormScreen.swift` удалены три связанных места:

- состояние `@State private var diagAlertMessage: String?`;
- модальный алерт `.alert("Диагностика", ...)` с кнопкой «Понятно»;
- присваивание счётчиков в `loadScreen()` — «Комментариев: N, событий: N, подшагов: N».

Другие файлы не тронуты. Экран «Настройки → Параметры сервера → Диагностика»
к этому окну отношения не имеет и остался как был.

## Проверки

- `python3 Tools/design-system-guard.py --diff HEAD` — чисто, новых нарушений нет.
- `xcodebuild ... -destination 'iPhone Air, OS 27.0' build` — **BUILD SUCCEEDED**.

  на iPhone). Проверка сделана кадром с экрана.
