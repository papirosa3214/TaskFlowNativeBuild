## Причина и исправление

В `NoteDocument.encodeList` условие продолжения списка сравнивало уровень и семейство блока. Функция `listTypeName` возвращает `bulletList` не только для маркированного пункта, но и по умолчанию для любого другого блока. Поэтому список захватывал следующие заголовки, абзацы, таблицы, код и разделители того же уровня.

Заголовок превращался в пункт списка; у таблицы текст хранится в ячейках, а `runs` самого блока пуст. Сериализатор записывал вместо таблицы пустой пункт списка. Механизм воспроизведён на исходнике до исправления и совпадает с повреждением карты. Исторический запрос, который испортил именно эту заметку, не установлен: журнал автора этой записи не исследовался.

Исправление: продолжать список только когда следующий блок действительно `isListItem`. Остальные блоки обрабатываются обычными ветками сериализатора.
