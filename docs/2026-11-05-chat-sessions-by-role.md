# Раздел «Чаты»: сессии по ролям

Поручение владельца 05.11.2026.

## Цель

Панель ролей у края остаётся прежней. Нажатие на роль показывает в центре её
сессии, а не шторку с «Личной комнатой» и «Новым чатом».

## Как устроено у других

| Программа | Кто работает | Единица разговора | Что ещё есть |
|---|---|---|---|
| Codex | агент | тред внутри проекта или сам по себе | лента по времени, архив |
| Claude Code | агент | сессия, привязанная к каталогу | возобновление, ветвление копией |
| OpenAI Agents SDK | агент | сессия с id и своей историей | хранилище истории подключается отдельно |
| LangGraph | ассистент: граф и настройки | тред с контрольными точками | запуск соединяет ассистента и тред |

Общая модель: **кто работает**, **разговор с собственной историей** и **один
запуск** — разные сущности, разговоры хранятся плоским списком одного вида.

## Что у нас отличается

- Слово «сессия» значит три разных вещи: строка списка (`chats`), контекст модели
  на пару «чат + роль» (`chat_sessions`) и маркер в ленте (`/new-session`).
- `chats` смешивает виды через `kind`, `room_kind`, `parent_chat_id`,
  `branch_of_chat_id`, `task_id`. Постоянная комната и сессия выглядят как разные
  сущности, хотя это одна таблица.
- Стек менять незачем: очередь доставки, поколения и память чата работают.
  Спорна модель понятий, а не технологии.

## Что сделано

- Сервер: таблица `chat_context_usage`, поле `context_usage` в `GET /api/chats`.
  Раньше замер жил только в памяти процесса.
- iOS: `RoleSessionList` выбирает сессии пункта панели, плоско по дате. Строка:
  название, последний ответ, контекст, дата, без аватарки.
- На панели новый пункт «Групповые чаты». «Чаты проектов» остались в своей вкладке
  и с аватарками, «Общая» не менялась.
- Шторка `RoleRoomSheet` убрана. «Новая сессия» — кнопка «+» в шапке.

## Решения по ходу, которые может поправить владелец

- Выбранная роль прячет вкладку за край, чтобы список был виден целиком.
- «Личная комната» идёт обычной строкой списка по дате.
- «Переписка с коллегами» перенесена из шторки под список сессий роли, иначе её
  негде было бы открыть.
- Под превью подпись «Работает»: без аватарки ход роли иначе не виден в строке.
- Контекст групповых чатов не показывается: в них у каждой роли своё окно.
