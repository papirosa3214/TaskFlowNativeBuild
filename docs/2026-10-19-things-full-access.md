# Things: доступ Помощника владельца

## Единая цепочка

Текст и голос → один универсальный `taskflow` → `taskflow_things3` → Mac TaskFlow Host → локальный Things. Список операций и схемы заданы в `~/.hermes/scripts/things_tools_contract.json`. Сервер хранит синхронизированную копию для описания. Это локальная автоматизация Mac, не REST API и не прямой доступ Linux к Things Cloud.

## Возможности

- Структурированное чтение: полный ID, название, заметки, даты, напоминание, статус, родитель, реальные теги и чек-лист из связующих таблиц; исходные поля и данные повторения сохраняются.
- База не изменяется: SQLite read-only backup в отдельную временную папку учитывает WAL и удаляется после чтения.
- Даты старта/дедлайна декодируются из формата Things (битовые поля); время напоминания — из отдельного битового поля; creation/modification/stop — Unix UTC. Статус 3 — выполнено, 2 — отменено.
- Создание и изменение задач/проектов — документированные Things URLs. Напоминание связывается с днём старта. URL token хранится локально с правами 0600, роль его не получает.
- Ответ «успех» при записи означает receipt `x-success` от Things. После него требуется перечитать поля: Things может проигнорировать несуществующий тег/заголовок. Таймаут — `may_have_changed`, повтор без проверки запрещён.
- `things_ui` — управление только приложением `com.culturedcode.ThingsMac` через Accessibility: посмотреть дерево, нажать элемент, выбрать строку, изменить текст, отправить ограниченное сочетание клавиш. Так доступны повторы и другие функции, отсутствующие в URL Scheme. Сначала `inspect`, затем действие с возвращённым snapshot и ID элемента, затем снова `inspect` для проверки. При изменившемся интерфейсе действие отклоняется. Рабочий стол/другие приложения/произвольная shell-команда инструменту недоступны.

## Условия

Mac Host должен быть в сети. Для работы через интерфейс нужен незаблокированный сеанс macOS с Things и доступом Accessibility. Проверка не запрашивает права сама и при отсутствии разрешения возвращает объяснение. Закрытый спящий Mac этот путь не обслуживает.

## Проверки

- Python: 16 целевых тестов PASS (включая WAL, настоящую кодировку дат и связи таблиц, URL receipt/error/timeout).
- Swift helper: сборка PASS, 4 теста протокола PASS; запрещены произвольные приложения/команды и глобальные сочетания клавиш.
- Host: 14 тестов PASS; JSON-RPC error и MCP isError не становятся успехом.
- Сервер: 13 целевых тестов PASS. Отдельная регрессия воспроизвела обрезку JSON голоса на 12000 символах; исправлена, голос возвращает полный envelope.
- Реальный read-only вызов голосового Unix socket → gateway → Mac → Things прочитал проекты. Дополнительная launchd-проверка подтвердила фактическую схему SQLite и доступность Accessibility из контекста Node.
