# Архивная карточка поломки исчезает из «Состояния системы»

Карточка TaskFlow `6dee5bc3-d750-493d-a69f-69f98780ba55`, шаг `fix`
(роль «Разработчик»). Реестр границ: `LOCK-SYSTEM-SUMMARY-CLOSED-INCIDENT-20261021`.

## Что записано в заказе

Владелец 20.10.2026: поломка в разделе «Состояние системы» порождает служебную
карточку починки. Если карточку отправить в архив — починка не нужна (например,
упёрлись в права доступа) — то запись поломки обязана исчезнуть из «Состояния
системы» и не возвращаться, пока та же поломка не возникнет снова.

Запись поломки живёт в трёх местах, и все три молчали:

1. уведомление типа `incident` в ленте («Уведомления») — лежало в базе навсегда,
   потому что архив карточки уведомления не трогал;
2. сводка «Состояние системы» — строка проверки из суточной сводки сторожей
   привязана к поломке по `incident_key`; поломка закрыта, а строка оставалась
   и продолжала ссылаться на архивную карточку;
3. `GET /api/system-state` — архивные поломки из ответа исключены, но сервер не
   сообщал клиенту, какие ключи закрыты: клиенту было нечем понять, что строку
   пора убрать.

## Что сделано

### Сервер (`New-Todoist`, .110)

- `server/src/lib/taskArchive.ts`: при архиве карточки с `incident_key` удаляется
  её уведомление типа `incident` (только этот тип, только эти карточки).
- `server/src/routes/notifications.ts`: `GET /api/system-state` отдаёт закрытые
  (архивные) поломки отдельным списком `closed: [{id, key}]` — по 200 последних.
  Ключ нужен строке проверки (`incident_key`), id — строке, привязанной к
  карточке (`diagnostic_task_ids`).

### Приложение (`TaskFlowNativeBuild`, мак)

- `Sources/Core/Models/SystemState.swift`: разбор ответа понимает поле `closed`;
  старый сервер без этого поля — не ошибка.
- `Sources/Features/Directory/Support/SystemSummaryRows.swift`: строка проверки,
  привязанная только к закрытой поломке, не рисуется. Живая поломка важнее
  закрытой: если та же поломка возникла снова (у неё новая карточка), строка
  возвращается.
- `Sources/Core/Stores/TaskStore.swift`: счётчик `archivedRevision` растёт, когда
  приходит событие «карточка ушла в архив».
- `Sources/Features/Directory/NotificationsScreen.swift`: по этому событию
  перечитываются сводка и лента уведомлений. Раньше экран их не перечитывал:
  карточка открывается шторкой (sheet), и `.task` на экране заново не срабатывает.

Модель поломок и правило «одна поломка — одна карточка» (`server/src/lib/incidents.ts`)
не менялись; сторож и их сводки не тронуты.
