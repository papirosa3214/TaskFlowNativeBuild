# Зоны свайпов в списке планировщика

## Поведение

В разделе «Планирование» свайп строки задачи начинается в полосе шириной 32 pt у левого или правого края строки. Это вдвое больше фактического внутреннего отступа контента (16 pt). Внутренняя часть списка переключает вкладки «Входящие», «Ждут вас» и «Сегодня». Краевой свайп не переключает вкладку, внутренний свайп не открывает действие строки. Список остаётся полноширинным.

Пока строка открыта или анимируется обратно, перелистывание вкладок выключено. Свайп по открытой строке из любой точки закрывает её; перелистывание снова доступно после завершения анимации возврата.

## Изменения

- `HorizontalPanZones` задаёт общие предикаты для краевых и внутренних зон и блокирует перелистывание, пока строка открыта.
- `HorizontalPanRecognizer` отклоняет свайп строки, начатый вне краёв.
- Закрытие строки снимает блокировку после завершения анимации, а не в момент назначения целевого смещения. При начале вертикальной прокрутки открытая строка тоже остаётся заблокированной до завершения закрытия.
- `TodaySectionView` принимает переключение вкладки только при начале жеста внутри глобальных границ списка.
- Другие экраны со строками задач сохраняют прежний свайп по всей ширине.
