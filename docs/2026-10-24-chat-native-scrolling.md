# Чат: переход на штатную механику прокрутки

24.10.2026. Реализация готова к проверке владельцем; живой сценарий и iPhone ещё не подтверждены.

## Решение владельца

Использовать стандартные механизмы Apple; убрать собственную механику перемещения ленты. Отдельным ответом владелец поручил **сохранить проявление текста**. Этот выбор заменяет предложенную ранее схему удержания собственного сообщения на 38% высоты из `2026-10-24-chat-smoothness-plan.md`.

## Что изменено

`Sources/Features/Chat/RoleChatsScreen.swift`:

- Удалены центрирование на 38%, динамическая распорка, измерение высоты ответа/своего сообщения и переключение позиции по переполнению.
- Удалены самодельное отслеживание фаз прокрутки для включения автоследования, отложенный scrollTo при каждой новой последней строке и контейнерная анимация кнопки вниз.
- Удалены snappy/withAnimation при отправке, подтверждении и ошибке сообщения.
- Положение хранит SwiftUI `ScrollPosition`. Первоначальный вход и выравнивание короткой истории задаются `defaultScrollAnchor`; при пользовательской позиции дополнительный нижний якорь sizeChanges не назначается. Отступы задаются `contentMargins(..., for: .scrollContent)`.
- Явные команды прокрутки остались для отправки, кнопки вниз и перехода из содержания. Они вызывают стандартный ScrollPosition без заданной нами кривой/длительности анимации.
- Наблюдение расстояния до низа осталось только для видимости кнопки и прежнего проявления текста; оно не выдаёт команд прокрутки.
- При тапе по ленте снимается стандартный FocusState поля. Обычные кнопки, ссылки и выделение необходимо проверить на устройстве: перехват жестов нельзя считать доказанным только по исходнику.

`Sources/Features/Chat/ChatVoiceComposer.swift`:

- Добавлен необязательный передаваемый FocusState.Binding; существующие другие места использования сохраняют свой локальный фокус.
- Удалены DragGesture над композером и собственный порог свайпа 38 pt. Закрытие при скролле обслуживает `scrollDismissesKeyboard(.interactively)`.
- Диктовка и вставка упоминания используют тот же binding фокуса.

Не менялись pacer, проявление букв, порядок шагов, идентификаторы сообщений, сервер и сеть. Внешний вид композера и его отдельные переходы при записи голоса не перерабатывались: эта работа касается перемещения ленты и взаимодействия с клавиатурой. Код других экранов не входит в результат.

## Проверка

- Архитектурные проверки `python3 Tools/test_chat_native_scrolling.py`: на прежнем исходнике 4 сценария дали 9 падений (включая subtest); после удаления механизмов — 4/4. Это проверки исходника, **не** UI-тест и **не** доказательство плавности в рантайме.
- Удалён только устаревший unit-тест порогов удалённого жеста.
- `RoleChatVoiceTests`: 10/10, 0 failures. Запуск `xcodebuild test-without-building`, только TaskFlowTests/RoleChatVoiceTests. UI-тесты не запускались.
- Сборка для симулятора и сборка для тестирования прошли. После корректировки contentMargins/ScrollPosition итоговая сборка также прошла (46,4 с). Повторная сборка понадобилась после обнаруженного смещения отступов/исчезновения строк при клавиатуре в промежуточном варианте.
- Design-system guard чист; git diff --check чист.
- Итоговый пример открыт на iPhone Air iOS 27.0, установлен только на симулятор. [Кадр](2026-10-24-chat-smoothness/native-scroll-short.jpg).

## Ограничение UI-проверки

XcodeBuildMCP сообщал об успешных tap/typeText, но снимки не подтверждали их результат. Через обычный accessibility-доступ Simulator удалось изменить черновик (только локальный пример, без отправки). После переустановки терялось дерево содержимого Simulator; интерфейс Simulator перезапущен. Нажатия, фокус и экранная клавиатура продолжили вести себя неоднозначно. Поэтому итоговое закрытие клавиатуры по свободному фону, длинный растущий ответ и сохранение ручной позиции **не объявлены проверенными**. Это конкретный оставшийся шаг, а не замена проверки скриншотом или unit-тестами.

Живые роли не запускались, сообщения не отправлялись, UI-тестов нет. На физический iPhone ничего не установлено, метрик FPS/hitches нет. «Идеальная плавность» не заявляется.
