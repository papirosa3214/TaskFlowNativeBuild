# Разделение разговоров и задач — уточнение владельца 14.11.2026

Чат — начало центральной сессии общения. Из него владелец может попросить
роль перейти к работе в слоте. Дальнейшая переписка по задаче идёт в comments
самой карточки, в её ленте активности. Отслеживание задач — отдельный инструмент.

В чатах не нужны отдельные комнаты задач, каталог назначений и ссылки
на карточки ради повторного отслеживания. Ошибочная попытка применить схему
комнат от 08.11 остановлена владельцем и не публиковалась.
Документ 12.11 «Чат Помощника и временные сессии ролей вместо комнат»,
раздел 9.2, подтверждает comments как место переписки по задаче;
это правило не ограничивается только режимом новых сессий.

## Интерфейс

Режим ролей: иконка открывает страницу выбранной роли с постоянным личным
чатом и остальными свободными разговорами/ветками. Профиль — в троеточии.
Разговоры с task_id и room_kind=task не включаются в каталог чатов.
Запрос /chats/:id/children для списка назначений убран: такого списка здесь нет.

Новые сессии: собственные экран, транспорт, состояние и хранение,
без добавления постоянных комнат ролей. Sources/Features/Sessions
и Packages/NewChatCore этой правкой не менялись.

Backend и БД не менялись. Старые серверные маршруты и записи физически
не удалялись; скрытие их из каталога не выдаётся за миграцию backend.
Автотесты не запускались по указанию владельца.
