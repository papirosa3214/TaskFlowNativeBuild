# Переключатели формы шага TaskFlow

8 октября 2026.

В PlanStepEditorSheet оба раздела зависимостей («Начать после», «Раньше шагов») используют общий TFToggle: системный Toggle, масштаб 0.82, красный tfRed. Подписи сохраняют прежний размер. Состояния и сохранение связей не менялись. Для VoiceOver сохранены подписи с назначением переключателя и описанием шага.

Проверка: сборка при XCUITest успешна; 1 UI test PASS. На живых данных открыта форма нового шага, проверено переключение и снят кадр. Форма закрыта через «Отмена», шаг не сохранялся. Раздел «Раньше шагов» использует тот же компонент; на проверенной карточке отсутствуют ожидающие шаги, поэтому этот раздел не показан на кадре.

Временный тест удалён, Xcode project перегенерирован. iPhone не устанавливался; сервер не перезапускался.
