# Свайп в архив без подтверждения

LOCK: `LOCK-SWIPE-ARCHIVE-NO-CONFIRM-20261012`

## Работа

Владелец: свайп в любом списке отправляет задачу в архив — убрать
подтверждение. Окончательное удаление из архива с подтверждением остаётся
(в архиве задача удаляется навсегда, свайп — обратимое действие).

## Результат

- Свайп влево по строке задачи отправляет её в архив сразу, без диалога.
- На экране «Архив» подтверждение окончательного удаления осталось.

## Что сделано

| Файл | Что |
|---|---|
| `Sources/Features/Today/TodayTaskRow.swift` | Диалог «Отправить задачу в архив?» удалён целиком вместе с состоянием `confirmDelete`; кнопка свайпа зовёт `onDelete()` напрямую |
| `Sources/Features/Directory/Support/DirectoryTaskRow.swift` | Диалог остался, но срабатывает только когда строка передаёт `deleteConfirmTitle` — то есть на экране «Архив» |

Ключ к разветвлению — уже существовавший параметр `deleteConfirmTitle`:
`nil` означает обычный список (архив), не-`nil` — экран «Архив»
(окончательное удаление). Проверено: `deleteConfirmTitle` передаёт только
`TaskArchiveScreen.swift:120`, других мест нет. Так что подтверждение
необратимого действия сохранено без новых флагов.

  в проект, пока не запущен `xcodegen generate`: xcodebuild радостно зелёный,
  а `totalTestCount: 0`. Всегда сверять `xcresulttool get test-results summary`.
