# Завершение хода чата, 07.11.2026

Причины: после playback cleanup удалялся endedTurnIDs, поэтому поздний
snapshot мог воскресить тот же ход. На сервере restartDelivery повторял
запрос даже после сохранения его частичного ответа из live draft.

iOS сохраняет tombstone до закрытия экрана. Текст показывается по мере
прихода с сервера без искусственного посимвольного проигрывания. Завершение
без pacer также освобождает строку сохранённого сообщения.

Сервер перед повтором проверяет ответ по chat + role + trigger и завершает
доставку с уже опубликованным результатом. Частичный ответ остаётся явно
прерванным; продолжение требует сообщения владельца. Пустой ход допускает
прежнее восстановление. Исторические дубли не удаляются.

Проверки: host Swift replay двух terminal-путей RED → GREEN; design guard.
Сервер: chatLiveDraft и chatQueueRecovery, 13 PASS, новый тест RED → GREEN.
Это проверка логики, не приёмка интерфейса на iPhone. UI-тесты, симулятор
и установка не выполнялись. Вид шагов оставлен существующей настройке.
