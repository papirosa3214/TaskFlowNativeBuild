## 3. Что изменено

### Сервер (.110, `server/src/routes/notifications.ts`)
- `GET /api/notifications?unread=true` — только непрочитанные. Параметр необязательный: без него ответ прежний, **старые сборки клиента не ломаются**.

### Клиент (этот репозиторий)
1. `TaskStore.load()` — **один** запрос `/api/tasks?include_children=true` вместо двух. Корневые карточки выделяются локально по серверному правилу (`parent_id IS NULL OR project_id IS NOT NULL`); сверено на живых данных: 126 корневых из 127 совпали с серверным списком до id.
2. `TaskStore.refreshAfterReconnect()` — больше **не тянет архив** (547 КБ): архив нужен только экрану «Архив», который грузит его сам.
3. `NotificationStore.load(unreadOnly:)` + `APIClient.notifications(unreadOnly:)` — на старте и при переподключении берутся только непрочитанные; полная лента грузится на экране уведомлений.
4. `TaskFlowApp` — при переподключении обновляются задачи и счётчик непрочитанных, а не вся лента.

**Итог по циклу:** вместо 4,7 МБ сырых — ≈ 2,0 МБ (список один раз + уведомления непрочитанные), по сети ≈ 400 КБ вместо 560 КБ и без архива. Реконнект больше не стоит полного кэша.

## 4. Что осталось (не сделано здесь)

- **Число переподключений** (30 675) не снижено — снижена их **стоимость**. Разбор причин (фон/сон/сеть) требует логов с iPhone.
- **Вариант B** (дельты `updated_since`, ETag/304) не начат — контракт API, отдельная задача.
- **Сборка и установка на iPhone** — за владельцем (на .110 нет Swift/Xcode).
- Счётчик «Получено от сервера» считает распакованные байты — в сравнениях с «Настройками → Сотовые данные» это разные величины.

## 5. Критерии проверки

- `GET /api/notifications?unread=true` отдаёт только непрочитанные; без параметра — полный список (старый клиент не сломан).
- Один заход на список задач = один сетевой запрос (в диагностике телефона «Запросы к серверу» не растёт вдвое).
- После разрыва связи телефон тянет только задачи и непрочитанные уведомления — без архива.
- Трафик в iOS «Сотовые данные» за 3 дня ≤ 20 МБ/сутки.
- Экран «Архив» и лента уведомлений работают как раньше (полный список по кнопке).
