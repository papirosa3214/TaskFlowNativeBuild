# Привязка iPhone по QR-коду

08.11.2026, `LOCK-DEVICE-PAIR-QR-20261108`.

## Задача

Владелец: «Да, это было бы идеально через QR-код».

Повод — выключение домашнего входа без пароля (`TASKFLOW_LAN_NO_AUTH=0` на
`.110` и в systemd-юните). До этого любой процесс в домашней сети получал
права владельца одним `curl` с заголовком `x-taskflow-client: ios-native`;
после выключения `POST /api/auth/lan` отвечает 404.

Обратная сторона: телефон ходит долгоживущим токеном устройства из связки
ключей, и если токен пропал (переустановка приложения, выход, ответ 401 и
очистка Keychain), вернуть сессию было нечем — только пароль владельца
руками. Привязка по QR закрывает ровно этот случай.

## Как это работает

1. На сервере: `cd ~/Проекты/New-Todoist/server && npx tsx scripts/pairing-code.ts`
   — печатает одноразовый код (128 бит, 32 hex), ссылку и ASCII-QR.
   Код живёт 5 минут, в базе лежит только его sha256, новый код гасит
   прежний. Внутри приложения тот же код выдаёт `POST /api/pairing/code`
   (владельцу, из «Настроек»).
2. В приложении: «Привязать этот iPhone по QR» на экране входа или в
   «Настройки → Сервер». Камера читает QR (`AVCaptureMetadataOutput`), либо
   код/ссылку вставляют текстом.
3. `POST /api/pairing/exchange` (без авторизации: код и есть вход) отдаёт
   долгоживущий токен устройства. Токен кладётся в связку ключей, дальше
   сессия обычная — `GET /auth/me` даёт полного пользователя для интерфейса.
4. Ссылка `taskflow://pair?v=1&code=…&host=…` открывается и камерой системы:
   `RootView.onOpenURL` поднимает ту же шторку с готовым кодом.

Поле `host` дома не используется — приложение работает по встроенному адресу
сервера. Оно нужно внешнему доступу через ретранслятор (отдельная задача).

## Что не проверено и границы

- Приложение не собиралось и не запускалось: симулятор без прямого поручения
  владельца не трогаем. Скан камеры проверяется только на телефоне — в
  симуляторе камеры нет, экран честно предложит ручной ввод.
- Внешний доступ через ретранслятор (поле `host`) не реализован: дома адрес
  сервера встроенный.
- Отзыв устройства по-прежнему на сервере (`DELETE /api/devices/{id}`).
