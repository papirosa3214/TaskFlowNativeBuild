# Телефон отвечает на команду сервера `device_op` (Apple Напоминания и Календарь)

Дата: 22.10.2026. Карточка: 9aca4795 (шаг `builder_2`). Контракт: заметка
«Контракт канала команд устройству `device_op`» (ffaf800d-19ad-40e7-8616-9482019f432e),
серверная часть — `server/src/device/protocol.ts` (коммит f9a01d19, в main).

## Что было

Сервер умел отправлять телефону команду `device_op` и ждать ответа, а сам
телефон команды не выполнял: в клиенте не было ни разбора `device_op`, ни
`EKEvent`, ни исполнителя операций. Живой вызов `apple_*` заканчивался
таймаутом.

## Что сделано в клиенте

1. **Протокол** (`Sources/Core/DeviceOpProtocol.swift`) — разбор команды
   `device_op` (`v`, `opId`, `op`, `arguments`) и сборка ответа
   `device_op_result` (`ok` + `data` либо `error.code`/`error.message`).
2. **Исполнитель** (`Sources/Core/AppleEventKitOps.swift`) — семь операций
   контракта через `EventKit`: `reminder.list`, `reminder.create`,
   `reminder.complete`, `reminder.reschedule`, `calendar.events`,
   `calendar.event.create`, `calendar.event.update`. Отказы честные и по
   контракту: `access_denied` (нет доступа), `not_found` (нет такого
   элемента), `invalid_arguments` (плохие аргументы), `op_unknown` (неизвестная
   операция), `version_unsupported` (версия контракта выше нашей), `internal`.
3. **Канал** (`Sources/Core/DeviceOpsChannel.swift`) — сокет устройства `/ws`
   с токеном устройства, разбор команды, ответ на тот же `opId`, переподключение
   при обрыве, ответ на `ping`. Токен устройства выпускает сервер
   (`POST /api/pairing/code` → `POST /api/pairing/exchange`), приложение делает
   это само своим входом владельца и хранит токен в Keychain
   (`KeychainService.deviceToken`).
4. **Подключение** — `RealtimeEvent` разбирает `device_op`, `RealtimeClient`
   отвечает на команду по тому же сокету, `TaskFlowApp` поднимает канал команд
   при входе владельца и останавливает при выходе.

## Договорённости по данным

- Даты — ISO 8601 с часовым поясом (`2026-10-22T09:00:00+03:00`), дата без
  времени — `2026-10-22`; без часового пояса — местное время владельца.
- Идентификаторы Apple (`calendarItemIdentifier`, `eventIdentifier`) возвращаются
  как есть и годятся для следующих операций.
- Удаления в контракте нет: стирать напоминания Помощнику недоступно.
- Отмена события (`cancelled: true`) в EventKit реализована удалением события из
  календаря — «отменённого» события в EventKit не существует.

## Ограничения

- Канал живёт, пока открыто приложение: в фоне телефон не отвечает (это
  осознанное ограничение контракта, §7).
- Телефон не спарен с сервером, пока приложение ни разу не запустилось с
  входом владельца: токен устройства выпускается при первом входе.
- Доступ к «Напоминаниям» и «Календарю» выдаёт владелец на телефоне — без него
  операции отвечают `access_denied`.
