# Единый тикет во «Входящих» — 30.10.2026

Поручение владельца: коротко показать суть обращения и требуемую реакцию,
убрать повтор названия задачи и лишние подробности. Дополнения: без системного
синего; разделительные линии и цветовые акценты по направлению обращения.

## Что изменено

Все обращения используют один `TFCard` и одну структуру:

1. Короткий заголовок: «Нужен ответ», «Согласовать план», «Изменить план»
   или «Ход заблокирован».
2. Суть: первая содержательная строка исходного обращения, максимум 160
   символов и две строки в карточке. Для согласования используется причина
   плана, для вопросов — первый вопрос, для блокировки — исходная причина.
   Дубли названия задачи и известные общие фразы сервера не показываются.
3. Роль и источник: «В чате» / «По задаче».
4. Действие: «Ответить», «Ответить на 3 вопроса», «Ответить в задаче»,
   «Рассмотреть план», «Разобрать блокировку» или «Открыть чат».

Название задачи, проект, дополнительные вопросы и длинный разбор из превью
убраны. Исходные тексты и данные не изменяются: доступ к ним — через прежний
переход к задаче, чату или форме ответов. Открытие карточки ничего не запускает.

Между тикетами добавлены `Divider`. Цветной только значок: вопрос — `tfPurple`,
согласование — `tfTeal`, блокировка — `tfOrange`; неизвестный тип — нейтральный.
Цвет отражает тип обращения, а не выдуманный приоритет: API тикета не отдаёт
отдельное поле срочности. Подпись типа остаётся видимой без различения цвета.
Синий из иконок и подписей убран, экран и форма ответов используют `tfText`
для системного tint по прямому поручению владельца.

## Ограничения содержания

Клиент не сочиняет краткое объяснение с помощью модели и не угадывает тип
технической неисправности. Перезапуск сервера появится в сути, только если
он указан в исходном обращении. Если там нет содержательного текста, остаются
тип, источник и доступное действие. Сокращение длинного текста может скрыть
часть контекста; полный источник открывается по тапу.

## Проверки

- `python3 Tools/test_attention_card_context.py`: 20 unit-тестов модели
  и 1 тест существующего сценария подсказки проходят на macOS.
- RED: новые сценарии сначала падали на прежнем отображении (`title`, `body`,
  `context_title`, прежние подписи действий), доступном через адаптеры свойств.
  Основной прогон — 16 нарушенных утверждений. Отдельно воспроизведены
  повреждение имени сервиса с `_` и ошибочная подпись неизвестного типа задачи.
- GREEN: краткие вопросы, число вопросов, план и его изменение, блокировка,
  неизвестный тип, отсутствие источника, ограничение длины и сохранность
  исходного текста проверены вместе с прежними тестами контракта.
- `swiftc -parse` трёх изменённых Swift-файлов — успешно.
- Сторож дизайн-системы и `git diff --check` — чисто.

Сборка, симулятор, UI-тесты и установка на iPhone не выполнялись. Внешний вид
оценивает владелец после новой сборки. Изменения только в нативном клиенте;
сервер прочитан для проверки контракта, но не менялся.
