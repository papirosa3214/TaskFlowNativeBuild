# Группа проекта и темы задач

03.10.2026. Реализовано локально; на устройство владельца не установлено.

## Как открыть

Чаты → «+» → «Группа проекта» → проект. Внутри группы: «Общее обсуждение» и темы задач. «Добавить тему задачи» предлагает карточки проекта, в том числе дочерние. Повторный выбор открывает ту же группу/создаёт ту же тему без дубля. В комнате темы есть существующая ссылка на карточку задачи.

Темы скрыты из общего списка чатов и находятся внутри группы; их непрочитанные входят в счётчик группы. Личные чаты продолжают работать. Новые поля RoleChat опциональны, старый ответ сервера декодируется.

## Проверка

Сборка симулятора PASS. Два теста моделей PASS. Временный XCUITest с синтетическим токеном и изолированной HTTP-фикстурой: открыть группу, увидеть две темы, открыть общее обсуждение, вернуться и открыть выбранную тему — PASS. Скриншот получен вложением XCUITest. Боевые карточки и модельные запуски не использовались.

Сервер: миграция 088_project_chat_topics, три новых маршрута и проверка доступа. Полный отчёт: /Users/max/Проекты/New-Todoist-server/server/docs/2026-10-03-project-topics-implementation.md.
