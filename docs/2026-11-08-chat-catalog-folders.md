# Каталог «Групповые чаты»: проект — папка комнат его задач

Спецификация: `2026-11-08-role-slot-chat-branches-spec.md`, §3 («проект открывает
список комнат своих задач»), §6 (подписи слотов), §13 (комнаты без проекта — вне
папок).

## Что было

Сервер после миграции `202_task_rooms` проектных чатов не держит: каждая задача
живёт в своей комнате `room_kind = 'task'`. Клиент об этом не знал:

- `ProjectChatScreen.swift` открывал «чат проекта» с горизонтальной полосой
  топиков (`api.chatTopics`). Полоса вела в чат, которого больше нет.
- `RoleSessionList.projectGroupID` решал, показывать ли этот экран.
- В каталоге «Групповые чаты» комнаты задач шли плоским списком.

## Что сделано

- `RoleSessionList`: `RoleSessionCandidate.folder`, `RoleSessionGroup`,
  `groups(_:scope:)`, `roomsCount(_:)`. `projectGroupID` удалён.
- `RoleChatsScreen`: комнаты разложены по папкам проектов, папка раскрывается
  (`openProjects`), у папки подпись «N комнат». Комнаты задач без проекта лежат
  ниже, без папки. В строке комнаты проект больше не повторяется.
- `ProjectChatScreen.swift` удалён, `RoleChatRoomLoader` всегда открывает
  обычную комнату, из `RoleChatRoomScreen` убран `topicStrip`, из
  `APIClient+RoleChats` — `chatTopics`.
- `RoleChatDetailsSheet`: под ролью видны её слоты с теми же подписями, что в
  выборе `@` («Разработчик 1», «Разработчик 2»).
- Подсказка `chats-project-folders` на первой папке каталога.
