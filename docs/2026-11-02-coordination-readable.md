# Окно координации: читаемый вид

Дата: 02.11.2026
Реестр: `LOCK-COORDINATION-READABLE` (`IN_PROGRESS` → `REVIEW`)

## Что было не так (по скриншотам владельца)

1. **Вместо названия шага — сырой JSON.** Подписи на графе, список шагов и
   очередь ожидания показывали описание слота плана:
   `{"key":"work_1","title":"Восстановить рабочий прокси хау-claude","result":"Порт 10811…","role":"infra_engineer","depends_on":[],"parallel_with":["work_2"]}`.
2. **Красная молния на обычном состоянии.** «Идёт работа» — это `active_run` →
   `.accentPulse` → иконка `bolt` и цвет `Color.tfRed`. Самое штатное состояние
   выглядело как тревога.
3. **Серые подложки.** Секции списка в дефолтном `insetGrouped`-стиле рисуются
   серыми карточками — окно выглядело набором блоков, а не текстом.

## Что изменено

| Файл | Что |
|---|---|
| `Sources/Features/Coordination/CoordinationScreen.swift` | `.listStyle(.plain)` — плоский текст без серых подложек |
| `Sources/Features/Missions/MissionControlScreen.swift` | То же для Mission Control |
| `Sources/DesignSystem/Components/CoordinationCauseColor.swift` | `.accentPulse` («Идёт работа»): цвет `tfRed` → синий (светлая тема `0.27/0.49/0.85`, тёмная `0.45/0.72/1.00`), иконка `bolt` → `arrow.triangle.2.circlepath`; `.darkOrange` — иконка `arrow.clockwise`, чтобы не повторялась |

JSON убирает **сервер** (см. `fix/coordination-slot-text`, PR #52): сервер хранит
описание слота в `subtasks.title` и сверяет по нему шаги, поэтому разбор сделан
там — на телефон уходит человеческий текст.

## Про анимацию

Пульсация активного узла уже была (`PulseModifier`, 1.2 с, амплитуда 6%) и
включается для `active_run` и `durable_queued_wake`. Она не изменилась — теперь
она видна на синем, а не на красном, и рядом крутится стрелка.

## Проверки

- сборка generic iOS — BUILD SUCCEEDED;
- сторож дизайн-системы (`--folder`, режим CI) — чисто; сторож заголовков — чисто;
- на iPhone ставится только по отдельному поручению владельца.

## Что осталось на решение владельца

Окно пока **наблюдательное**. Управление процессом живёт в других местах: чат с
оркестратором, план совместной работы в карточке, вердикт критику. Сведение
управления в одно окно (чат с исполнителями из координации, окно исполнителя по
тапу на граф, тумблеры) — следующий шаг, он требует разведки API чатов и
решения, как выглядит «панель управления миссией».
