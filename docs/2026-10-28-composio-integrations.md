# Composio в Интеграциях — 28.10.2026

## Изменение
Composio убран с экрана «Сервер MCP» и перенесён в отдельную секцию
«Настройки → Интеграции → Composio». Ссылка подключения Linear ведёт туда же.
Подключённые сервисы Composio показаны в «Подключениях TaskFlow» со статусом
«Подключено»; Linear и Gmail сохраняют свои существующие строки без дублей.

Список использует общий GET /api/integrations/composio. Подключённый GitHub
берётся также из services, поэтому не пропадает, если его нет на текущей
странице каталога. После возврата из браузера состояние обновляется.
Каталог и доступ ролей загружаются одним общим запросом вместо запроса на роль.
Для записи «GitHub MCP» добавлено объяснение: обычный аккаунт подключается
через отдельный сервис «GitHub».
