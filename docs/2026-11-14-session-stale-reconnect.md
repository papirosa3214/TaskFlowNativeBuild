# Поздний ответ при смене сессии

Обновление снимка и получение пропущенных событий после ожидания сети проверяют, что сессия по-прежнему активна. Ответ прежней сессии не устанавливает её снимок и не применяет события к новой.

Проверены синтаксис Swift, diff и сторож дизайн-системы. Поведенческий прогон гонки и приложение не проверены; требуется ревью. Общий курсор событий не менялся: сервер сначала ищет его в общем журнале, затем фильтрует события по сессии.

Защита не решает гонку событий и снимка одной сессии, а также переключение туда и обратно до ответа. Эти случаи остаются открытыми.

Дополнение: поколение активной сессии меняется при смене снимка на другую сессию. Запросы обновления и догонки проверяют его после ожидания, включая переход A → B → A; снимок также сверяется с запрошенным id. Проверены синтаксис и сторож дизайн-системы, поведенческое ревью требуется. Порядок одновременных снимков одной сессии и прочие команды открытия остаются отдельной работой.
