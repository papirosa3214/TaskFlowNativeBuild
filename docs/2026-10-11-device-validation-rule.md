# Проверки на физическом iPhone — правило проекта

По поручению владельца 11.10.2026 в AGENT-CYCLE.md, раздел 7, закреплён
проведённый цикл проверки чата: воспроизведение и регрессия, точный XCUITest,
настоящий механизм в фикстуре, симулятор и физический iPhone, измерение
hitches/CPU/памяти, кадры и xcresult, сохранение доказательств и обычный
запуск приложения после тестов. AGENTS.md содержит обязательный указатель.
Раздел установки согласован с обязательной приёмкой UI на устройстве.

Команды сверены с локальным `xcodebuildmcp device test --help` и
`device launch --help`. Изменена только документация; сборка приложения
и повтор ранее прошедших физических тестов для этой правки не требуются.
