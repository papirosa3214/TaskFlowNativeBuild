# Представление карточки задачи

04.10.2026. Запрос владельца: сохранять выбранное раскрытие при выходе и возвращении; переходить к родительской задаче из раздела плана.

## Изменения
Разделы сохраняются в UserDefaults по taskID. Отсутствие записи означает прежние настройки первого открытия; сохранённый пустой список означает, что владелец всё свернул. Карточки не разделяют одно общее состояние.

Сохраняются также раскрытие текста задачи, текущих действий слота и предыдущего результата. Для слота ключ содержит taskID и sourceSlotKey; запись происходит в момент переключения. Выбранные данные читаются при создании экрана, без последующего раскрытия с анимацией.

В дочерней карточке заголовок «План совместной работы» сохранён, под ним «Общий план и запуск в родительской задаче» и кнопка с её названием. Используется существующий переход между карточками; если карточка не предзагружена, используется существующая navigationDestination.

## Проверка
XCUITest воспроизвёл потерю раскрытия после повторного открытия до изменения. Проверяются открытое/закрытое состояние после terminate/launch и нажатие ссылки в родителя. Проверки пройдены: повторное открытие раскрытого плана/живых действий, повторное открытие свёрнутого плана/живых действий, переход по ссылке в родительскую карточку. Действия проверяются по идентификатору внутри слота, чтобы текст на фоновой карточке не давал ложного успеха. device BUILD PASS, git diff --check PASS. Данные и порядок задач не меняются. Состояние хранится на устройстве, синхронизация между устройствами не добавлялась.
