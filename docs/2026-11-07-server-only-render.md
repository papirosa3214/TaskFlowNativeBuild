# Чтение только из серверных блоков — 07.11.2026

## Поручение
Удалить запасной локальный разбор ответов чата, чтения заметок и описаний карточек. iOS отображает подготовленную сервером структуру.

## Изменения
- Из `RoleReplyMarkdown` удалены fallback на `ChatRichContent.split` и `MarkdownParser`, включая разбор ячеек таблиц. Нет серверных блоков — явное сообщение об ошибке получения, исходник не интерпретируется.
- Удалены сам локальный разборщик rich content и восстановление текста из незавершённого JSON. Пока JSON не готов, используется уже существующее состояние ожидания.
- Живые ответы и размышления отображают серверные блоки; локальная подмена текста переводчиком больше не отбрасывает эти блоки.
- Заметка при загрузке и после сохранения получает TipTap из `content`; Markdown остаётся исходником редактора. Неверный/отсутствующий серверный документ вызывает ошибку, а не пустую заметку.
- Предпросмотр результата заметки также читает серверный документ. Таблицы документов рисуются из готовых ячеек.
- Сервер отдаёт карточке `title_document`, `description_document`, `description_blocks`. Модель iOS сохраняет эти поля, просмотр использует готовые блоки, начальная загрузка и тихое обновление редактора используют готовые документы.
- Сравнение описания не разбирает серверный Markdown и сохраняет отличие реальной правки владельца от повторной привязки массива блоков.

## Граница
Это удаление разбора при чтении. Обработка локального ввода в блочном редакторе карточки, MarkdownEncoder для сохранения и локальные подсказки не удалены. Имя существующего рендера сохранено. Данные БД не мигрировались.
