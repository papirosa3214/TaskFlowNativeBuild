# Дубли текста при завершении ответа — 30.10.2026

По снимку владельца: обрывки абзацев над повторным полным ответом.
`RoleChatLiveTurn.completed(with:)` безусловно добавлял сохранённые текстовые
элементы к уже показанным. Теперь сохранённые тексты заменяют промежуточные
по порядку, лишние промежуточные элементы удаляются; действия сохраняются
и продолжают объединяться по ID. Повторное завершение не умножает текст.
Устранены лишние текстовые блоки и связанная с ними работа layout/отрисовки.
Кэш и открытие чата внизу не изменялись.

Проверка: `python3 Tools/test_chat_completion_text.py` — RED на прежнем коде
(три обрывка + полный ответ), GREEN после (только полный ответ, действия
сохранены, повторное завершение стабильно). Настоящий метод собирается
swiftc на macOS с минимальными моделями. Parse и design guard прошли.
